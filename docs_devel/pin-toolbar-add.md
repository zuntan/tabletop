# ツールバーからピンを追加する

ピンも他のパーツと同様、ツールボタン1回で1本を置き、追加したピンを選択する。連打してから移動できる。机クリックによる連続配置モードは廃止。

## シリーズの選び方

- 選択中のピンが同じシリーズなら、そのシリーズへ追加。他種パーツと混在していても、ピンのシリーズが一つなら優先する。
- ピン未選択・複数シリーズ選択なら最後に使ったシリーズへ追加。
- 隣の小さな「▾」は全シリーズの一覧。選ぶとそのシリーズへ1本追加し、追加先として記憶する。
- 「新しいシリーズ＋1本」はシリーズと最初のピンを同じバッチで追加する。一回のUndoで両方戻る。
- 最初のピンを削除しても、シリーズは残る。空のシリーズだけ増やす専用UIは設けない。
- 追加先の記憶は現在のタブ内だけ。別の机をロードして記憶したシリーズがなければ、その机の先頭シリーズを使う。
- シリーズ選択メニューの下に「ピンの順番変更はAIに相談してください」と案内する。削除時の欠番は詰めず、自動の番号振り直しUIは設けない。配置は使用頻度・見つけやすさに応じて今後調整できる。

配置位置は他の新規パーツと同じ画面内の位置を基準とし、少しずらす。共通スナップに従ってピン先端を合わせる。新規配置時に周囲へ勝手に接着はせず、ドラッグで対象のアンカーへ留める。

名前・色・形などの編集は既存のピン設定へ残す。プロパティ内の「シリーズを追加」はツールバーの新規作成へ統合。保存形式、最大番号＋1の採番、シリーズ削除／最後のピン削除の扱いは変更しない。
