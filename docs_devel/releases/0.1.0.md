# Tabletop 0.1.0

人間とAIが同じ机で資料を広げ、並べ、つなぎながら考える、Tabletopの最初の公開リリースです。

## できること

- ブラウザとMCPから、同じ机を読み取り・編集できます。会話は普段のAIエージェントで続けます。
- カード、画像、図形、Mermaid、リンク、QRコード、落書きを置き、線やピンでつなげます。
- クリップ・クリアファイル・定規で整理し、ハンコ・シール・リアクションで印を付けられます。
- 道しるべやピンから経路をたどり、離れた場所へ視点を移動できます。
- 机ファイルの保存・読込、PDF・PNG出力、AIに接続しない静的ページ版を利用できます。

## 導入

添付の **tabletop-0.1.0.zip** を取得し、展開したフォルダーの **INSTALL.md** に従ってください。Node.js 22.12以降とnpmが必要です。MCPサーバーの起動にはソースと依存パッケージも使うため、ビルド後もフォルダー全体を保持してください。

この配布ZIPはリリース元のコミット情報を同梱し、Aboutに表示します。GitHubが自動生成する「Source code」アーカイブには、この追加情報はありません。添付の `tabletop-0.1.0.zip.sha256` でZIPを照合できます。

インストール前に、[チュートリアル机](https://zuntan.github.io/tabletop/?desk=desks/tabletop-guide.tabletop)をブラウザから試せます。公開Pages版はmainの更新に合わせて更新され、0.1.0に固定されたものではありません。

## 利用前に

- **自動保存はありません。終了・再読み込みの前に机を保存してください。** Undo履歴は保存ファイルへ引き継ぎません。
- 開発者はCodex・Copilot・piで利用していますが、動作確認に使用したモデルはいずれもGPT-6.1-Solのみです。その他のエージェントやモデルでは未確認で、同じ判断・操作結果を保証するものではありません。
- PDF・PNG出力は机をラスタ画像にしたものです。拡大時の解像度には限りがあり、Web資料の埋め込みページは内容そのものを画像化しません。
- 外部URLの机や画像は、接続先の公開状態やCORS等の制約を受けます。静的ページ版はAI接続を行いません。
