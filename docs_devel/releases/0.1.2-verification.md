# Tabletop 0.1.2 verification

Scope: prevent Windows license generation changes from blocking Git updates. No application features, MCP protocol changes or desk format changes.

Release candidate: `f3bfa58f8bb054bf771f609ded05fe4960d17401`.

## Reproduction and update

- A temporary v0.1.0 clone with `core.autocrlf=true` generated 260 modified license files after `npm ci` and `npm run build`.
- Pulling current main stopped on `public/licenses/THIRD_PARTY_NOTICES.txt` and `public/licenses/generated/manifest.json`.
- On a new old-version checkout, restored generated license changes, pulled the fix and ran generation twice: clean Git status.
- Ran the normal build after that upgrade: clean Git status.
- The tracked license changes in this release are line-ending normalization only, except the expected lock-file hash update.

## Automated and distribution checks

- Unit tests: 338 passed, including LF/CRLF generation, unchanged legacy CRLF output preservation, obsolete notice removal and production license closure.
- Normal build and Pages build passed.
- Extracted the release ZIP without Git, ran npm ci, both builds and all 338 unit tests successfully.
- Browser checks: About shows 0.1.2 and the candidate hash; license links work; synchronized README desk text fits. Two browser tests passed.
- The final ZIP differs from the fully tested archive only in Windows CI configuration and updated provenance. Rebuilt and checked About with the final hash.
- Local checks used Node 24.22.1. Windows CI used Node 22.
