## Dependency audit observation

Fresh `npm ci` succeeded (290 packages). Registry audit at verification time reports two moderate vulnerable transitive packages: `@hono/node-server@2.1.5` and `hono@4.13.13`, both introduced by the MCP SDK. No high or critical advisories were reported. Full machine report: `/tmp/tabletop-v020-audit.json`.

The Tabletop server imports MCP stdio transport and uses Node's HTTP server and `ws` for its browser connection (`src/server.ts`); it does not import Hono or the SDK's StreamableHTTP transport. The SDK imports `@hono/node-server` in its separate `server/streamableHttp.js` and Hono in an example. The described Hono routes are not used by Tabletop's current transport. This is a code-path assessment, not a claim that the dependency tree is vulnerability-free. Dependency patch updates should be tracked separately; the already tagged candidate was not silently rewritten.
