# Tabletop 0.2.0 release verification

Status: local preflight passed; distribution and GitHub checks follow the tagged candidate. Publication remains a separate human confirmation after reviewing the release-note draft.

## Scope and notes

Compared with v0.1.2: Markdown tables/task toggles/automatic links, rendered text selection and Markdown-aware copying, AI text selection, same-desk/external image references, per-desk fonts, layer and clip ordering, eight resize handles, Wireloom cards and local text patches, shared held diagram previews, and the MCP application version fix.

Japanese and English public notes are in docs/release-notes.md and docs/en/release-notes.md. The draft GitHub body is 0.2.0.md in this folder. INSTALL and package/lock metadata target 0.2.0. The public README desk includes current Japanese installation and authoring instructions; live browser text measurements were used to fit its document cards.

## Local checks

Environment: Ubuntu, Node 24.22.3.

- Normal and Pages builds passed.
- Unit tests: 381 passed, including actual MCP initialization version matching package.json.
- Selected browser checks: 18 passed, covering Markdown/images/selection/copying, AI text positions, editor height and held previews, Mermaid/Wireloom, media anchors, static Pages and the English tutorial.
- An initial browser run had one test observation race: the resize test sampled the expected first ResizeObserver update as instability. It now waits for that initial transition before measuring twelve consecutive frames; ongoing resize loops are still detected. Both standalone checks and the full selected set passed afterward.
- Windows generated-file CI now also regenerates Wireloom twice and checks that its committed renderer remains clean, in addition to license generation.
- Existing desks still load. New object types/settings may be rejected by older application builds; this is described in the release notes.

Logs: /tmp/tabletop-v020-{build,pages-build,unit,browser-final}.log. Distribution and CI results will be recorded after the candidate is tagged; the tag must not move after publication.
