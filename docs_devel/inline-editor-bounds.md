# カード入力欄の開始サイズとAI分割

2026-10-26合意。対象はMarkdownカード（type:text）のインライン編集。図形や画像タイトル・Mermaidソース欄の仕様は変更しない。

- 表示矩形を基準に入力欄を幅320〜800 CSS px、高さ160〜480 CSS pxへ補正する。
- 操作欄と余白を含め、workspaceとブラウザ表示領域の共通部分に収める。小画面では通常の下限より画面内に収まることを優先する。
- 位置はカード左上を基本に、はみ出した分だけ補正する。本文は16px、行高1.4。元カードの文字サイズやズームから独立する。
- サイズ補正は編集開始時のみ。その後は通常のtextarea手動リサイズとスクロールを利用する。再描画による位置追従では開始サイズへ戻さない。
- 本文を確定してもカードの位置・寸法・文字サイズは変更しない。未確定Markdownプレビューは入力欄と同じ寸法・フォントを用いる。
- textareaの幅はpxで独立させ、ResizeObserverは親だけを追従させる。百分率幅と親幅更新の循環を再導入しない。

AIが意味単位で分割する場合は [card-splitting](help/card-splitting.md) を参照する。原本は保持し、分割先・クリップへ付属物や接続を複製しない。専用の分割UIは作らない。結合手順は保留。

## リンク・資料入力欄の幅追従（2026-10-28）

リンクの表示名欄を手で広げたとき、入力欄だけがパネルの右へはみ出していたため、本文以外の編集にも幅追従を適用。編集パネルとURL欄を同じ幅へ伸ばす。QR・Mermaidの内容欄を広げた場合もタイトル欄と揃える。

各textareaは親の100%幅から独立したpx幅を保持し、ResizeObserverは実際に幅が変わった欄を基準に揃える。親子が相互に拡大するループは作らない。初期幅は表示領域へ収め、位置も表示領域へ補正する。カード本体の位置・サイズ・フォント設定は変更しない。既存のMarkdown本文の開始時サイズ補正・プレビューは維持する。

## 旧authoring資料からの補足（2026-11-03）

`src/inline-editor.ts`・`src/clipboard.ts`を照合。確定キーは `tabletop.editor.submit-key` に保存し、利用できなければタブ内だけ保持する。Enter確定／Shift+Enter改行と、Enter改行／Ctrl・Meta+Enter確定を切り替える。ソース編集欄はその専用の確定操作を使う。Escで取消、外側クリックで確定するが、IME変換中のキー入力を確定・取消として扱わない。編集1回は1回のUndo、新規作成の取消では未確定オブジェクトを残さない。

リンク・Web資料のURL、画像・SVGの任意リンクはHTTP(S)に限定し、不正な値では確定しない。任意リンクは空欄で解除する。右上の外部リンク操作とカード本体の選択・編集を分ける。

SVG文字列の貼り付けはDOMへ直接挿入せず、画像として取り込む。DOCTYPE／ENTITYを拒否し、XMLの解析結果・SVGルートと名前空間を検証する。旧資料の5MB上限は更新済みで、現在は素材1点10,000,000 bytes。[分割転送・共通上限](binary-transfer.md)を参照。机間のコピー照会とフォールバックは[机をまたぐコピー](cross-desk-clipboard.md)、未確定原文の確認は[Markdownプレビュー](markdown-preview.md)へ分離する。

原文・机名の編集中は、AIからの変更・選択・Undo／Redo・ロード・枠調整などを拒否し、編集終了後の再操作を求める。参照操作は可能。カメラ移動等にも編集との競合ガードがある（`src/main.ts`）。
