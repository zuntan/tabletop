# 接合部の丸め

2026-10-20、`feat/junction-rounding`。自由なベジェ操作は保留し、線の接合点を丸める道具を追加する。

## 操作とデータ

線のプロパティ「接合部の丸め」を数値で指定する。候補は「なし (0)・小 (48)・中 (96)・大 (192)・特大 (384)」。線の両端に適用し、端点個別の設定は持たない。

MCP・保存では `junctionRounding`（0〜100000、省略は0）。単位は机の座標と同じで、接合点から各線に沿って戻る距離。両側の線に指定があれば大きい方を採用する。両方0にすると丸めない。

2本だけの端点が属する接合点に、接合点を制御点とする二次曲線を一つ描画する。論理的な端点・接合ID・バインディングは変更しない。通常の移動・端点操作・Alt切断・複数選択は既存の接続ルールに従う。Undo、コピー、保存にも数値が含まれる。

## 描画上の制限

- 実際の戻り距離は、指定値と両側の線長の45%のうち最小。短い線の両端を丸めても直線部分が残る。指定値そのものは書き換えない。
- 3本以上の分岐、長さ0、一直線・折り返し、接合位置の不一致は丸めない。
- 接合点側に矢印・丸・ひし形がある場合、またはいずれかの線幅が0の場合は丸めない。記号や不可視線の意味を維持する。
- 曲線の色・幅・線種は、指定値の大きい線を採用する。同値ならID順で決める。異なる線種・色の間では境界が見える場合がある。
- 選択ハンドルは論理的な接合位置に残す。曲線もクリック可能。ダッシュの位相は各描画要素で始まる。

## 確認

単体テスト：戻り距離、曲線の重複防止、大きい値の採用、短い中間線、分岐・記号・直線・切断、Undo。
ブラウザ：候補選択、両線の描画、保存復元、Undo、切断。既存の端点接合・線種テストも実行する。
