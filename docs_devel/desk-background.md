# 机の壁紙とタイトル背景色

2026-10-18に内蔵の3種類を追加。2026-10-19に暗い無地と壁紙別の枠色を追加。「メニュー → 机の見た目」で壁紙やタイトル背景色を変更できます。画像の持ち込みは未実装。UIテーマは[独立した切替](./ui-theme.md)。

## 試用の柄

| `wallpaper` | 見た目 |
| --- | --- |
| `none` | 従来の無地とドット。初期状態 |
| `wood` | 薄い木目と板の継ぎ目 |
| `cutting-mat` | 緑のカッターマット。細線・太線・中央目印 |
| `pink-notebook` | 淡いピンクのノート。罫線と余白線 |
| `charcoal` | 暗いチャコールの無地。既定ではドットなし |

柄は内蔵SVGパターン。外部画像やフォントの取得は行わない。机上の座標に固定し、パン・ズームで机と一緒に動く。壁紙は文書のパーツではなく、選択・当たり判定・一覧・全体表示の範囲に含めない。

## AIから切り替える

既存の `desk_execute` へ `background_update` を追加。

```json
{
  "operations": [
    { "kind": "background_update", "patch": { "wallpaper": "wood" } }
  ]
}
```

`cutting-mat`、`pink-notebook` も同じ操作。無地へ戻すには `none`。

暗い机は `charcoal`。UIのダークモードを切り替えても壁紙は変わらない。

## 壁紙に合う枠色

| 壁紙 | 人間の選択 | AIの指差し |
| --- | --- | --- |
| none | #2563eb（青） | #15803d（緑） |
| wood | #1d4ed8（青） | #7c3aed（紫） |
| cutting-mat | #facc15（黄） | #e879f9（ピンク） |
| pink-notebook | #1d4ed8（青） | #047857（緑） |
| charcoal | #60a5fa（明るい青） | #a3e635（黄緑） |

`settings.background.selectionColor` / `pointingColor` はそれぞれの上書き色。nullは壁紙の既定色を使う指定で、机ファイルへ保存する。壁紙を指定したbackground_updateでは、上書き色を既定へ戻す。同時に上書き色を明示すればその値を優先。壁紙を指定せず色だけ更新する操作も可能。Undo・読込で机と一緒に復元する。

選択枠・リサイズハンドル・ロック中の枠とバッジ・囲み選択・接続端点の通常色に適用。Binding済み端点の緑は接続状態を示すため保持。AIの点線枠にも適用する。人間とAIの区別は色に加えて枠の位置・線種・ハンドルの有無でも維持する。

`desk_settings`／`desk_context` の `settings.background` で取得できる。

```json
{
  "wallpaper": "none",
  "color": null,
  "showGrid": null
}
```

- `color: null` は柄の既定色。色の指定で背景色を上書きできる。nullへ戻すと、その柄の色へ戻る。
- `showGrid: null` は自動。無地では従来のドットを表示し、柄付きでは重複を避けて非表示。true／falseで明示的に上書きできる。
- 部分更新。省略項目は維持する。色やグリッド表示を以前に上書きしていた場合、柄の既定へ戻すにはそれぞれnullを指定する。
- ドットの表示はグリッド吸着のON/OFFとは別。壁紙変更でスナップの設定・座標を変えない。
- 変更は共有revision・履歴・Undoの対象。1つの操作として戻せる。
- 机の外観を変えるため、人間の意図がある場合に操作する。

パーツの位置・寸法・色・文章・採番・選択、UIの配色、カメラの位置は変更しない。半透明のパーツから背景が透ける見え方は変わる。

## 保存と互換性

机の設定として保存・読込する。柄は識別子だけなので画像アセットを増やさない。保存形式versionは1のまま。

backgroundを持たない古いファイルは、従来どおりの無地・ドットに補完する。一方、backgroundを含む新しいファイルは、古いアプリの厳密なSchemaでは拒否されるため、UIとMCPを揃えて更新する。

新サーバーから古いUIへ背景の変更を要求した場合は、保存・UI更新を案内して編集前に拒否する。

## 後続

設定画面、ライト／ダークテーマ、任意の画像・柄の取り込み、細かなサイズ・濃さ調整は未実装。必要になってから検討する。


### 壁紙の不透明度
`background.opacity`（0〜1、既定1）を `background_update` で変更できる。
壁紙の色・模様・背景グリッドを一つの層として固定の中間グレー `#808080` に重ねる。
0ならグレーだけ、1なら従来の壁紙。パーツ・枠色・UIテーマは変更しない。
机ファイルへ保存し、Undo対象。旧ファイルは1。テーマや壁紙の切り替えで自動変更しない。
設定画面は今回追加せず、AI経由で調整する。


## 人間側の設定
ヘッダーの「読込」の右にメニューを配置。「机の見た目…」で壁紙、不透明度、選択枠・AI指差し枠の色を調整する。
枠色は「壁紙に合わせる」でプリセットへ戻す。壁紙選択時も枠色はプリセットへ戻る。
不透明度スライダーは操作中プレビュー、確定時に1回だけ履歴へ記録。閉じた際の未確定プレビューは戻す。
設定は即時反映・机ファイルに保存、Undo可能。パネルは非モーダルで机を見ながら調整できる。


下地は `background.underlayBrightness`（0=黒、1=白、既定0.5）でグレースケール指定できる。
「下地の明るさ」スライダーは左が白、右が黒。プレビュー・確定・保存・Undoは不透明度と同じ。
従来の固定グレーは初期値として維持し、壁紙・UIテーマの切替ではこの値を変えない。


## 画像の木目（試用）
壁紙メニューは無地、木目1、木目2、フローリング、カッターマット、ピンクのノート、チャコール。
`wood-1` と `wood-2` は提供画像を1672×941ワールド単位でタイル表示する。パン・ズームに追従する。
継ぎ目は現時点で許容。既存 `wood` は見た目・保存値を維持して表示名だけ「フローリング」に変更。
画像はアプリ同梱の同一オリジン素材であり、パーツや机ファイル内の画像アセットではない。
不透明度と下地の明るさも引き続き利用できる。

フローリングは提供素材public/wallpapers/wood_floor.svgのfloorパターン（960×450）とgrainを利用。SVG全体の1600×900をタイル化せず、内部パターン単位で繰り返す。


## 机を見分ける色（2026-10-23）

「メニュー → 机の見た目」の壁紙候補は、無地、無地（アイボリー）、無地（淡い青）、無地（淡い緑）、無地（淡いピンク）、無地（淡い紫）、その下に従来の木目などの順です。

| 候補 | `wallpaper` | `color` |
| --- | --- | --- |
| 無地 | none | null |
| アイボリー | none | #fffaf0 |
| 淡い青 | none | #eff7ff |
| 淡い緑 | none | #f0faf3 |
| 淡いピンク | none | #fff2f5 |
| 淡い紫 | none | #f7f2ff |

新しい壁紙画像やパターンIDは増やさず、既存の無地と背景色の組で保存します。無地系は同じドットと枠色を使います。UIで壁紙候補を選ぶと、候補本来の色へ戻します。AIからのbackground_updateは従来どおりcolorを明示して上書きできます。

同じ画面の「タイトル背景色」は `settings.background.titleBackground` に #RRGGBB 形式で保存。nullまたは省略は従来のタイトル背景色です。「標準に戻す」で解除できます。壁紙の不透明度、UIテーマ、接続の有無とは独立し、接続状態によって自動変更しません。机のタイトル・配置と接続マーカーの配色は維持し、背景が明るいときは見出しの文字を濃くして読めるようにします。

どちらも机ファイルに保存し、LOAD・アップロード・Undo／Redoで復元。localStorageにあるUIテーマとは別です。古い机は新項目がなくても従来の色で開けます。新項目を含む机を扱うMCPサーバー・ブラウザは両方更新してください。

AIから変更するときも、利用者の指定に従ってbackground_updateを使います。壁紙色に合わせて勝手にタイトル色を変える仕組みはありません。
