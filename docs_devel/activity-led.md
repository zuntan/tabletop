# AIとの通信ランプ

2026-10-18。マスターの「君の存在をボードでも確認したい」という相談から、LANポートのランプのような小さな合図を追加。

- 下部ステータスバーの右端に、直径15pxのカラーLEDを一個。画面の資料や操作ボタンには重ねない。
- ブラウザがMCP経由の命令（method）を受けたら点灯。命令の処理時間とは同期しない。
- 緑（#00ff00）の単色。2026-10-19、多色から単色へ試用変更。成功・失敗等の意味や凡例は持たせない。
- 白いハイライトは中心の不透明度約30%、55%地点で透明にする。外側の光は維持し、緑を見やすくする。
- 点灯120ms、消灯60ms。連続する同色の命令でも消灯を挟む。
- 点灯中とは別に待機4件まで。満杯なら古い待機を捨て、新しいものを残す。全命令を正確に再現する表示ではない。
- 切断・ページ非表示・ページ離脱で点滅と待機を消去。復帰時に古い点滅を再生しない。
- 動きを減らす設定では、連続点滅を避け、通信が落ち着いて700ms経つまで点灯する。
- ポインター操作を妨げず、点滅ごとの音声通知や自動読み上げはしない。

ブラウザが受けた通信の気配を示す。AIの思考・実行中・接続の生存・進捗・成否を示すものではない。サーバー内で完結する管理操作や、接続用ハンドシェークは対象外。表示のためのポーリングや命令の追加送信はしない。

文書・選択・revision・Undo・保存形式を変更しない。バッファは画面の一時状態で、保存しない。
