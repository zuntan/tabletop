# AIから机全体をPDFへ保存

2026-10-29／Tabletop 0.1.0

`desk_pdf` は接続したブラウザの既存 `deskPdf` を使い、机全体をサーバー上のPDFへ保存する。人間向け「PDFで開く」と同じ単一ページのラスタPDFで、ズーム・スクロール・選択や指差し枠に依存しない。机・選択・履歴・未保存警告の基準は変更せず、別タブも開かない。AI接続なしのPages版に変更はない。

```json
{"deskId":"接続一覧で確認したID","path":"/absolute/path/guide.pdf","overwrite":false,"expectedRevision":123}
```

- `deskId`・`path` は必須。`expectedRevision` は任意で、生成開始時のrevisionを検証する。
- 絶対パスの親ディレクトリは既存のものを指定する。単純なファイル名は `TABLETOP_SAVE_ROOT`（既定 `~/.tabletop/saves`）へ保存する。相対ディレクトリや `~` 展開は受け付けない。拡張子は `.pdf`。
- 既定では同名ファイルを拒否する。明示的な `overwrite:true` の場合のみ、既存の机保存と共通の一時ファイル・原子的置換処理で上書きする。シンボリックリンクや通常ファイル以外は拒否する。
- 応答は保存先 `path`、`bytes`、`mimeType`、撮影時の `sessionId`／`revision`、世界座標の `bounds`、`raster`（幅・高さ・縮尺）、`webCount`。
- Web資料のiframe本文は既存PDFと同じプレースホルダーになる。外部画像・フォントの読み込み等も既存PDFの条件に従う。
- PDFサイズ・解像度は既存PDFの制約に従う。MCP転送は最大14 MiBに制限し、超過・生成失敗・I/Oエラーを通知する。ブラウザ橋の20 MB制限内にbase64とメタデータを収めるための上限。
- 古いブラウザでは生成できない。机を保存してから最新版へ再読込する。切断やタイムアウト時は自動再実行せず、保存先の有無を確認する。

「ひとりで考える」中も読み取りとして生成できる。PDF保存は `.tabletop` の保存ではなく、元の机の未保存表示を解除しない。

## 検証

単体試験：revision競合、ブラウザ必須、保存先・PDFデータの検証、既存ファイル保護、明示上書き、シンボリックリンク拒否。
ブラウザ試験：MCPと人間向け出力のバイト一致、カメラ独立、机状態保持、新規タブなし、revision競合、既存ファイル保護、ひとりで考える中の出力。
