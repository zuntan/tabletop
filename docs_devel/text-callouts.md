# テキストの吹き出し（試用）

2026-10-19、feat/text-callouts。ピンの取り付けをmainへマージ後に着手。

## 基本操作

テキストのプロパティ「吹き出し」のパレットから「なし／三角／考え事／引き出し線」を選ぶ。
有効にすると選んだ形のしっぽと、その先端を動かすハンドルを表示する。
先端はテキスト・基本図形・ピンのアンカーへ接続可能。線や自分自身へは接続しない。
通常ドラッグで接続先を選び直し、Alt＋先端ドラッグでは再吸着しない。

## 付け根の自動配置

本文の中心から先端への方向で上下左右の辺を選び、角丸を避けた位置へ付け根を置く。
しっぽの付け根の幅は最大72ワールド単位（初期試用の2倍）。小さい枠では縮める。
本文の輪郭としっぽは一つの閉じたパスで描画する。輪郭の二重描画や半透明の重なり線を作らない。
先端が本文枠内に入ったら、しっぽを描かない。
角の方向を越えると付け根の辺が切り替わる。滑らかさや辺の固定は試用後に検討する。
本文のMarkdown・余白・編集・文字の収まり測定は従来の枠を利用する。

## 移動・保存

- 接続先の移動・リサイズでは先端だけが追従し、本文は動かない。
- 本文を動かすと、未接続の先端は一緒に移動。接続済みの先端は対象アンカーに留まる。
- ピンへの接続は、固定画面サイズの表示にも先端を合わせる。
- 接続先を削除しても本文と先端はその場に残し、接続だけ外す。
- 「なし」への変更では本文を維持してしっぽを除く。
- 保存・読込・Undo・Redo・コピペに対応。コピーに含まれる対象は新IDへ振り直し、含まれない対象への接続は外す。
- フォーカスと範囲選択の境界にはしっぽの先も含める。本文の編集枠・アンカー・リサイズは本文枠のまま。

## MCP

text.calloutは{x,y,style?:speech|thought|leader,binding?:{objectId,anchor}|null}。x/yは先端のワールド座標。
省略またはnullで無効。接続があれば先端座標は対象アンカーから再計算する。
本文と先端は一つのパーツ。本文のサイズや色は既存フィールドを使い、付け根の位置は保存しない。
互いの本文を指す吹き出しも、本文の移動依存を作らないため再帰的な追従にはならない。

## 今後相談すること

ユーザー案：吹き出しを何パターンか選びたい。「◁」と「.oO」（考え事の泡のような表現）を構想中。
今回は基本の三角しっぽだけで操作を確認する。種類・付け根の固定方法などは後で相談し、追加仕様を先に確定しない。

## 検証

単体162件成功。ブラウザで有効／無効、実ドラッグによる接続・Alt切断、対象リサイズ、Markdown維持、保存・Undoを確認。
同時にピンの取り付け・線の接合も確認。

試用で三角の付け根3倍は太く感じたため2倍に調整。.oOは3倍程度の広さも候補とし、種類ごとに幅を調整する方針。具体的な数値や操作は後で相談する。

## 考え事の吹き出し（.oO）
style:thoughtを追加。省略は従来の三角（speech）。種類切替でも先端座標・接続を保つ。
付け根から先端への中心線上に大中小の輪を並べる。先端の手前に余白を残し、輪の最小半径と輪同士の間隔を確保。短い場合は2個・1個・非表示と減らし、潰れた輪を作らない。
輪の大きさは三角とは独立した計算。本文と輪を一つのパスの独立した部分として描き、パーツ色と透過設定を共有する。
単体163件・ブラウザ3件成功。見た目は実机で試用する。

輪の中心は中心線の0.5:1:1:0.5分割位置（1/6・1/2・5/6）に固定。半径はその位置に収まる範囲で調整。短く3個が収まらない場合は2個（1/4・3/4）、1個（1/2）へ減らす。

## 引き出し線
style:leaderを追加。本文は角丸枠、しっぽは短い外向きの線＋先端への斜線、先端は小さな丸。付け根と折れ位置は自動。先端座標・接続は種類を切り替えても維持する。線と丸は本文の輪郭色・線幅を利用。先端が本文枠内なら線は描かない。
