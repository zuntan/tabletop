# 8点アンカーとピン中央への接続

2026-10-18。線・矢印の接続を拡張。ピンの直接取り付け、線同士の接続・相互追従は今回含めない。

## 接続点

矩形・角丸矩形・楕円・テキストの接続候補は、上下左右と四隅の8点。

`top` / `right` / `bottom` / `left` / `top-left` / `top-right` / `bottom-left` / `bottom-right`

- 矩形の四隅は枠の四隅。
- 角丸矩形・角丸テキストは、角の円弧の45度位置を使用。半径は描画と同じ制限値。
- 楕円の斜め4点は、中心から各軸の半径の1/√2だけ離れた輪郭上の位置。
- メディア（画像・SVG・Web・リンク）と線・矢印は、従来どおり接続先にしない。

ピンは全形状共通で `center` の1点だけをマウス吸着の候補にする。中央はパーツの外枠中心であり、丸い頭の中心・先端とは区別する。ピンが画面上で一定サイズのため、表示中の中央へ線を合わせる。

従来のピンへの上下左右の接続は、保存データ・既存の呼び出しとの互換性のため保持。勝手に中央へ移し替えない。MCPでも以前の指定は引き続き解釈する。新しくピンへ接続する場合は `center` を使用する。

## 操作

- 線・矢印の端点をドラッグすると、新しい候補点を表示し吸着する。
- 選択中の1〜2パーツから線・矢印を作る操作も、図形の縦横比を考慮した8方向から接続点を選ぶ。ピンは中央。
- MCPは従来と同じ `startBinding` / `endBinding` の `anchor` に新しい名前を指定。
- 移動・リサイズ・Undo・削除時の接続解除、保存・読込、コピーは既存の接続機構を共用。
- 明示したBindingはグリッドより優先。角丸の斜め位置は格子上にならないことがある。
- 保存形式version 1のまま。新しいアンカーを含む保存データは、旧アプリのSchemaでは読めないためUIとMCPを更新する。

## 将来の「くっつける」は別途設計

利用者はカード・直線・ピンを将来くっつけたいと考えている。一方、ピン同士の関係は糸で表せるため、直接取り付けの必要性は再検討する。

現在はカード等の位置を元に、線の端点が一方向に追従する。カード3枚を線3本で三角につなぐことはできる。線同士の相互追従や、辺の長さを保った変形まで含めると、循環と拘束の解き方を決める必要がある。

ピンを対象へ直接取り付ける機能、追従方向・循環・解除・サイズ変更時の振る舞いは今回の土台の後で考える。新しい直接取り付けのデータ形式は追加していない。
