# 線と糸のズーム追従／太さ固定

2026-10-29実装・MCP再起動後に利用者確認済み。線オブジェクトのプロパティと、ピンシリーズ設定の「糸」に同じスイッチを置く。

**ズーム追従｜スイッチ｜太さ固定**

左のズーム追従が初期値。右の太さ固定をONとする。線はオブジェクトごと、糸はシリーズごとに指定する。

## データとAI

- 線：`fixedWidth:boolean`。未指定はfalse（ズーム追従）。線以外への指定は拒否する。
- ピンの糸：`series.thread.fixedWidth:boolean`。未指定もfalse。
- AIは既存の`desk_execute`で線をupdate、糸をseries_updateして設定できる。get／settings等にも公開する。専用ツールは追加しない。
- コピー、保存読込、Undo／Redoで保持する。線の書式スポイトにも含める。

今回、互換のために従来の糸の太さ固定を維持する特別処理は設けない。既存の糸も未指定ならズーム追従になることを利用者が了承。リリース確定後は後方互換を考慮する方針であり、この扱いを無条件に継続しない。

## 描画

太さ固定はSVGのnon-scaling-strokeで線幅と破線・点線の間隔を固定し、矢印・丸・菱形の端点装飾も逆倍率で描画する。ただし、ごく短い線では従来の線長に対する装飾サイズ制限を維持し、端点装飾の重なりを抑える。

線の位置・長さ・接合点・角丸め半径は常に机上座標。角丸めの曲線にも同じ線幅モードを適用する。線のマウス判定は画面上で最低14px、太い線では表示線幅以上を確保する。端点ハンドルや選択枠の大きさは変更しない。

PNGカメラとPDFは既存どおり100%相当の描画を基準とし、撮影時の机のズームに左右されない。出力解像度に伴う等比縮小は両モードに適用する。分岐ミニマップも同じ描画処理を使う。
