# 図形パレットと文字サイズの自動調整

2026-10-20、feat/diagram-shapes。吹き出し機能をmainへマージ後の段階。

## 形と近似

図形ボタンのパレットに、既存の矩形・角丸矩形・楕円と、追加の5種類をまとめる。
フローチャート専用の記号体系ではなく、机で意味や関係を表す形として扱う。

| 形 | 新しい操作用アンカー | 文字の収まりの近似 |
|---|---|---|
| ひし形 diamond | 上下左右の4頂点 | 楕円 |
| 平行四辺形 parallelogram | 外接矩形の上下左右4点 | 矩形 |
| 円柱 cylinder | 同上 | 矩形 |
| 書類 document | 同上 | 矩形 |
| 雲 cloud | 楕円近似の上下左右4点 | 楕円 |

4点の名前はtop/right/bottom/left。ひし形の4頂点は同じ外接枠の楕円の4点と一致する。
追加図形への斜め・center指定は拒否する。既存の矩形・角丸・楕円・テキストは8点のまま。
ピン・吹き出し・線の接続は共通のアンカー処理を使い、変更に追従する。
複雑な輪郭への厳密な接点計算はしない。

## 文字サイズ

図形内の文章は中央揃えのプレーンテキスト。改行は明示されたものを使う。
文字サイズ調整のパレットで次を選べる。

- 完全自動（textFit:auto）：枠に合わせて拡大・縮小。
- 縮小のみ（textFit:shrink）：指定fontSizeを上限に、必要な場合だけ縮小。

矩形近似は枠の内側、楕円近似は楕円の内接矩形を目安にする。
余裕を12ワールド単位取り、ブラウザのCanvas文字幅と行高1.25から表示サイズを計算する。
ひし形も楕円と同じ計算を使う。多少のはみ出しは許容する設計。
表示のための文字サイズは保存値を書き換えない。保存するのは指定fontSizeとtextFit。
計算結果は1〜1000の範囲に収める。

新しくUIで作る図形は縮小のみ。既存ファイルのtextFit省略は、従来の指定サイズを維持し、
パレットには「指定サイズ（既存）」と表示する。選択肢は新しい2モードのみ。
テキストパーツとピンの文字サイズは従来どおりで、この自動調整の対象外。

## データと実装

既存のrect/roundedRect/ellipseのtype値は維持。新しいtype値5個を追加する。
表示名・輪郭・近似分類をshape-definitionsに集約し、アンカーと文字調整は共通処理にする。
保存・読込・Undo・コピーに対応。MCPも同じtypeとtextFitを利用できる。
UIだけでなくMCPから自動調整したい場合はtextFitを明示する。

## 検証
