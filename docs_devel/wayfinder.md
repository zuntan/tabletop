# 道しるべ：経路をたどる視点移動

2026-10-28／分岐ミニマップ・AIの線端指定起動・ピン前後移動まで利用者確認済み。初版：`feat/wayfinder-navigation`、拡張：`feat/wayfinder-branches`。

## 今回の範囲

離れた2つのカードなどを、つながる線に沿って行き来する。片側に道しるべがあれば片道、両端にあれば同じ経路を往復できる。単なる最短距離のジャンプではなく、机の位置関係が移動の過程から分かること、見ていて楽しいことが目的。

独立オブジェクト `type: wayfinder`。UIの「道しるべ」で追加する。見た目は仮の矢印看板（初期72×72）で、後から打ち合わせる。

- 本体の余白をクリック・ドラッグして選択・移動する。
- 看板色は既存の塗りパレットから変更する。初版の人間向け配色操作は看板色のみで、輪郭・支柱・再生記号の色は追加しない。
- プロパティの二択ボタンで「移動／観光」を設定し、道しるべごとに保存する。属性 `wayfinderMode: move | tour`、省略時は従来どおり移動。コピー・保存・Undoでも維持する。
- 本体内に収めた丸い再生ボタンで経路をたどる。看板と再生記号は線の接続方向（上・左・右）を向く。フォーカスしてEnter／Spaceでも起動。
- 下端の先端をカード等のアンカーへ近づけて取り付ける。Altドラッグで吸着を外す。単独配置も可能。
- 下は対象への取り付け用。上・左・右が線の接続先となり、**3点合計で経路線は1本だけ**。
- 取り付けには既存の `attachment:{objectId,anchor}` を使う。対象の移動・リサイズに追従し、削除時は現在位置で外れる。道しるべ同士やピンへの取り付けはしない。初版はピンと同様、クリアファイルへ直接収納しない。
- 矢印の向きは進行方向へ影響しない。

## 移動

1. 現在のズームを保ち、出発する道しるべの中心へ視点を寄せる。
2. 接続された線・線の接合点を順にたどる。連続線・フリー連続線も通常の線と同じ構造で利用する。
3. 到着先オブジェクトを中心へ表示して停止する。接続先のない線端でも停止する。

到着先が道しるべなら、その取り付け先カードの中心まで進む。初版では各道しるべの経路線が1本なので、途中GOを通過する複数経路構造は扱わない。

画面は小さなマーカーを追い、原則としてズームを変えない。「移動」は発進・停止をsmoothstepで加減速する。経路長を画面上の距離へ換算し、走行時間は800〜5000ms。「観光」は周囲を眺めるため、経路上を画面120px/秒（仮値）の等速で進み、5秒上限は適用しない。両方とも出発地点への中央寄せは180〜600ms。移動時間・見た目・マーカーは実際に使って調整する仮値。

角丸めは既存の描画と同じ二次曲線を使用し、曲線ごと24分割して弧長に沿う移動へ変換する。直線の分割数に速度は左右されない。曲がり角だけの特別な減速は未実装。

## 経路の判定

接続端の `startBinding/endBinding` と `startJunction/endJunction` を利用し、近くの線や単なる交差から接続を推測しない。

分岐までは走行し、その地点を中央にして進路選択を待つ。入ってきた線は選択肢から除外する。一意な接続はそのまま通過し、単なる交差は無視する。自動走行中に同じ線を再訪するループは終了する。

分岐カンバンは背景を暗くしない吹き出し。地図は320×240 CSS px、机の0.25倍の固定縮尺で分岐を中央に置く。各方向へ80px離したボタンを置き、重なり回避はしない。近い角度の配置は利用者側で調整する。線の端点装飾を再現し、地図外の端点は境界に方向の手掛かりを示す。矢印は移動方向を制限しない。

方向ボタンで再発進。停止ボタン・Escape・カンバン外クリックで中止する。外クリックは背後のカードやリンクへ渡さない。経路変更・非表示・別カメラ操作でも待機を解除する。

## 中止・保存

マウス・タッチ・キー操作、別の道しるべやカメラ移動、画面サイズや表示状態の変化、机の編集・削除・ロードで中止し、その場に留まる。自動再開しない。reduced motion設定時はアニメーションを省略する。

視点移動はドキュメントの編集ではなく、revision・Undo・選択状態を変更しない。経路と取り付けは通常のオブジェクトとして保存・ロード・Undo・コピーに対応する。コピーに含まれない取り付け先・線の接続先は外す。

## AIから移動を開始する

`desk_wayfinder_start({deskId,id})` で既存の道しるべから出発する。`{deskId,lineId,from:"start"|"end"}` なら道しるべなしで線の指定端から出発する。両方の指定は不可。透明な線も経路に使える。任意の `mode:"move"|"tour"` は今回の走行だけに適用し、保存設定は変更しない。省略時は道しるべの設定、線からなら移動。

返答は `status: started` であり到着の保証ではない。走行終了までツールを占有しないので、観光中も読み取り等のツールを使える。人間の操作・机の変更等で中止される可能性があり、自動再試行しない。人間の注目先を動かすため、依頼や会話上の必要がある場合に使う。ひとりで考える・編集中・確認中・スクロール直後は既存カメラ操作と同じく拒否する。

`desk_camera_get` は走行開始後に任意の `navigation` を返す。`runId`、`status: moving|waiting|completed|cancelled|failed`、モード、起動対象、停止理由を含む。分岐待ちは `reason:branch` と地点・選択肢、終了は `arrived|line-end|loop`、中止は `human|changed|hidden|superseded|timeout`。これは最新1回のタブ内状態で、保存・履歴ではない。AIへのpush通知や到着待ちの保証は設けず、必要時に読む。

オブジェクトアニメーションとの同時実行、速度・所要時間指定は別途検討する。現在は机の編集で走行を中止するため、同時アニメーションの制御は未実装。

## 今回に含めないもの

道しるべへの複数経路、完成デザイン、専用速度設定UI、専用コンテキストメニュー。詳細な構想は[提案書](go-navigation-proposal.md)。

## 検証

- 単体：取り付け追従、3接続点・1本制限、角丸経路、交差・矢印の扱い、分岐選択肢・ループ終了、両端の往復、弧長、所要時間上限、保存・コピー・Undo。
- ブラウザ：画面外の折れ曲がる経路を固定ズームで移動し到着カードへ中央寄せ。走行が編集扱いにならないこと、中止とマーカーの片付け。

## 分岐拡張の検証

道しるべなしの線端指定、分岐待ちと再発進、地図の矢印、外クリックによる中止、待機中の経路変更、AIによる状態取得をブラウザで確認済み。ピンは前後移動、根元への到着、到着ピンへの選択切り替え、端の無効表示、複数選択時の非表示、ズーム・revisionの維持、操作による中止を確認済み。

## ピンの糸をたどる

ピンを1つ選ぶと、その近くに画面上の固定サイズの［◀ ▶］を表示する。同じシリーズの番号順（同番号なら文書順）で前後のピンへ移動する。前後が存在しないボタンは無効。複数選択・ピン以外・選択解除・ピン非表示・選択ピンが画面外の場合は表示しない。

出発ピンの根元を中央へ寄せてから、隣のピンの根元まで糸と同じ直線をたどる。移動の加減速・ズーム維持・操作による中止は道しるべと共通。糸の表示をOFFにしてもシリーズ順は利用できる。到着時は到着したピンを選択し、そのピンの［◀ ▶］から続けて移動できる。途中で中止した場合は選択を移さない。

ポップアップは一時的な選択UIで保存対象外。新しい属性・ショートカット・AIツール引数は追加しない。走行状態は既存の `navigation` に `pinId` とともに表れる。
