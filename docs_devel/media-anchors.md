# 画像・SVG・Mermaidの接続アンカー

通常の画像・SVG・Mermaidカードは、上下左右と四隅の8点へ線・ピン・吹き出しを接続できる。接続点はタイトル帯を含むカード外枠の矩形が基準で、画像の実描画領域・余白・透明部分は考慮しない。図を内部要素へ分解したり、SVG内の線へつないだりはしない。

移動とサイズ変更には接続先が追従する。相手を削除すると接続を外して端点を保持する。保存・コピー・Undoは既存の接続表現を使う。新しいアンカー形式は追加せず、既存のtop/right/bottom/left/top-left/top-right/bottom-left/bottom-rightを利用する。

小物（prop）は別の用途で、アンカーもリンクも持たない。小物の仕組みをコミット後に、通常のメディアへのアンカーを追加した。
