# 線・矢印の線種

2026-10-19。糸と同じ見本付きパレットで、実線・破線・点線を選ぶ。線・矢印の個別プロパティにのみ表示し、選択は即時反映する。線幅の候補や直接入力も即時反映。適用ボタン全体の整理は別の課題。

線・矢印の任意属性 `dash: solid | dashed | dotted` として保持する。省略は実線。旧ファイルの読込や、他の種類のパーツに既定キーを追加しない。線幅に比例した間隔で描画する（破線は4倍／3倍、点線は1倍／2倍）。矢印の先端は従来どおり塗りつぶす。端点・Binding・当たり判定は変更しない。

保存・読込・Undo・構造コピーは共通のパーツ属性として扱う。保存形式versionは1のまま。未知のキーを拒否する旧版ではdashを含むファイルを読めないため、UIとMCPを揃えて更新する。新属性を公開する今回は、ブラウザ更新だけでなくMCP再起動も必要。

## 両端の形と線の統一

線・矢印の内部データはtype=lineに統一。startMarker／endMarkerをそれぞれnone・arrow・circle・diamondから選び、始点／終点のパレットで即時変更する。両矢印、逆向き矢印、丸、ひし形の組み合わせが可能。マーカーは端点から線の内側へ描き、先端をBindingの位置に保つ。矢印の向きは各端から外向き。短い線では両端の形を縮め、長さゼロでは描画を省略する。

「線」「矢印」の作成ボタンは維持し、同じlineパーツをなし／なし、なし／矢印で作る。線種・線幅・色・接続関係は独立して保持する。

端点の見やすさを調整し、マーカーの基準寸法を25%拡大。丸とひし形は横幅も広げる。描画する線の本体だけをマーカーの内側まで控え、太線がマーカーの先端からはみ出すのを抑える。端点座標・操作ハンドル・当たり判定・Bindingは動かさず、途中の破線・点線とマーカーなし側の丸い線端は維持する。端点クリップの試作は廃止し、描画座標の補正に一本化。

旧type=arrowは読込・追加の入口だけでtype=line、startMarker=none、endMarker=arrowへ変換する。旧lineは両端none。明示的な端点属性は保持する。新しく保存・返却するオブジェクトはlineのみ。Git内の過去の.tabletopをすべてデコードし、パーツ数・ID・旧矢印の向き・線幅を検証する。過去アーカイブの書換えは行わない。
