# 連続線・フリー連続線

2026-10-27。入力方式だけを拡張し、生成後はtype:lineと既存接合・角丸めを使う。新しい保存形式やポリライン編集モードは追加しない。目的は少ない操作で道路地図・概念図を描き、後から普通に編集できること。

## 操作

- 「線」本体は従来どおり1本追加。隣の▼で連続線／フリー連続線を選ぶ。
- 連続線：始点、次の頂点を順にクリック。各線分はその時点で確定し、次点への仮線を表示する。Enter／Esc・ツール切替・画面外クリックで終了、確定済み線は残す。閉路は既存の始点に戻ってクリックして終了。専用の途中頂点編集は持たず、終了して既存操作で修正し、端点から描き足す。
- フリー連続線：ドラッグ中は仮の軌跡。離すと少数の直線へ清書し、選択モードへ戻す。Esc・pointercancel・ウィンドウ失焦などは未確定ストロークだけ破棄する。
- 終了後は今回生成した、現在も存在する線をまとめて選択する。クリック式は1線分ずつ、フリー式は1ストロークをUndo1回で戻す。描画中のCtrl/⌘+ZとShift+Zもクリック式では対応する。
- 連続線はクリックごとに既存アンカー・線端点・グリッドへ吸着。フリーは始点・終点のみ。Altは吸着を解除する。
- Space／中ボタンによる既存パンは連続線の合間に使える。フリードラッグ中はズーム・別ポインター操作を受け付けない。

## 清書

2 CSS px程度の間隔で軌跡をサンプリングし、最大4096点。上限時は間引く。RDP許容誤差は画面上の対角長の2.5%（6〜18 CSS px）を机上単位へ換算し、最大24線分になるまで粗くする。画面上の対角長6px未満はクリック同等とし、ゼロ長線も生成しない。

手ぶれより意味のある角を残すこと、精密な再現より修正しやすい少数線分を優先する。直線フィッティングや交点補正は初回には導入しない。曲線の近似品質は実機で使い、Undoでやり直す前提で調整する。

## 既存機能との接続

- 線の色・幅・線種は現在の書式を利用。端点の矢印は最初はなし、junctionRoundingは既存の小相当48机上単位。既存プロパティから変更可能。
- 接点はstartJunction/endJunction。始終点が既存端点なら同じ接合IDを共有し、既存線側への変更も同じUndoに含める。図形アンカーにはstartBinding/endBinding。
- 閉路も通常の端点接合として保存。3本以上の分岐で丸めない等、既存ルールは維持する。
- 線端点への新しい接合はロック・ファイル収納中の線を対象外にする。図形・カードの既存アンカーは現行の接続ルールで扱う。非表示ピンは候補外。
- 仮線は専用の一時SVGレイヤーで、保存・PDF・オブジェクト数に含まれない。机が外部変更されたら描画を終了し、古いrevisionで追記しない。AIによる変更は人間の描画中に拒否し、参照は可能。

検証は単純化・接合・吸着・閉路・保存・Undoの単体試験と、実際のクリック・ドラッグ・中断・継ぎ足しのブラウザ試験。
