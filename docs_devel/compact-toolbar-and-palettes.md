# 操作帯の折り畳みと用途別パレット

2026-10-30。操作にかかる手間を減らし、机上の内容に集中できるようにする。

## 上部の操作帯

ヘッダー末尾のSVG折り畳みアイコンで上部3段をまとめて畳む。タイトル色を持つ高さ32pxの帯に机名・接続状態・UNDO・REDO・ロック・SVG展開アイコンだけを残す。Pagesでは従来どおり接続状態を隠す。机名は一行で省略表示し、全文はホバーで確認できる。名前編集などは展開後に行う。

UNDO・REDO・ロックは元のDOMとハンドラーを利用するため、通常表示と同じ無効／ロック状態を表示する。右パネルと独立し、下部の表示操作もそのまま利用できる。カメラの変換値や机データは変えず、机の表示領域だけを広げる。編集中の切替は抑止する。

`tabletop.topbar.collapsed` をブラウザlocalStorageに保持。机ファイル・UNDOには含めない。ボタンは28px角、アイコン16px、上下余白2px。展開時のタイトル帯のUNDO・REDO・テーマ・メニューも28px角／16pxアイコンにそろえ、ファイルと「ひとりで考える」も28px高とする。展開時のタイトル帯は上下4px余白・高さ48px、操作間の間隔6px。上部のリビジョン表記は `rev.` に短縮する。開閉アイコンは一重の山形SVG（線幅2）。右余白は開閉どちらも8pxに統一する。

## 色パレット

既存の全42色は残し、「おすすめ／全色」をその場で切り替える。初期はおすすめ。塗りは淡い2段階、輪郭は中〜濃色、文字は濃い2段階、シールは識別しやすい中彩度〜鮮明な色から各14色。透明の選択肢は従来どおり、シールには設けない。

切替で色を適用したり既存の色を書き換えたりしない。選択色が候補外でも保持する。切替状態を `tabletop.palette.{fill|stroke|text|sticker}.mode` に保存し、同じ用途のパレットで共有する。机設定ではなくブラウザの操作設定。
