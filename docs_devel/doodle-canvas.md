# 落書き（初版）

ボタンで空のSVGカードを置き、紙の矩形を調整してからダブルクリックで専用キャンバスを開く。再編集可能。通常SVGと異なり、リサイズは紙だけを変更し、範囲外の線は原本に保持する。タイトルは机と編集画面で共通。

`type:svg` の任意属性 `doodle` が原本。`background:null|色`、`offset:{x,y}`、`strokes:[{tool:pen|eraser,color,width,points:[{x,y}]}]` を保持し、通常の `src` は寸法と原本から生成する。AIは既存のget/executeで参照・更新でき、asset_readで生成SVGを取得する。一般SVGのパスを編集履歴に変換しない。

丸ペン、消しゴム、太さ2/4/8/16/32、変更できる色3枠、透明／単色背景。描画の点は約0.6表示px未満の重複だけ抑え、清書や形状認識を行わない。ゴシゴシ塗れるが塗りつぶし・筆ペン・マーカー・貼り付けは初版対象外。

消しゴムは直前までの線へSVGマスクを適用し、その後の線を消さない。紙の背景はマスクの対象外。絵全体の移動はoffsetを変更し、ペンと消しゴムの両軌跡を一緒に移動する。Space＋ドラッグ／中ボタンは表示のパン、ホイールは表示倍率を変更する。紙の座標・寸法は変わらない。

編集画面だけのUndo/Redoでストローク・全消去・背景・全体移動を戻す。確定が机の履歴1件。キャンセルは原本を変更せず、先に置いた空カードは残る。編集中は机の通常UIをモーダルで遮断し、MCPの変更・視点操作も既存の編集抑制へ接続。クリアファイル内は取り出してから編集する。

原本の上限は512ストローク、1本10000点、全体100000点。履歴は100段かつ概ね500000点を目安に古いものから破棄。長時間の作画は別カードへ分割する。専用ドローソフトの代替にはしない。

原本付きカードは生成SVGだけの差し替えを拒否する。AIはdoodle原本を更新するか、別の通常SVGカードを作成する。サーバー側のスキーマと保存処理へdoodle属性を反映するため、利用開始前にMCP再起動が必要。

単体271件、ブラウザによる描画・局所Undo/Redo・再編集・紙リサイズ・キャンセル・色変更・AIの机Undo拒否を確認。赤線を消し、透明部分とその後の青線を画素で照合。通常版／Pagesビルドを確認済み。利用者の操作感確認は次段階。
