# 定規レイアウト

2026-10-27実装。レイアウトコンテナという共通概念を、既存クリップ・クリアファイルを全面改修せずに拡張した。モデル、描画、ジェスチャー、ファイル、コピーは同じ経路を使い、Pages版でも利用できる。

利用手順・データ仕様は [AI向け共通説明](help/rulers.md)。`desk_help({topic:"rulers"})`からも取得できる。

- resolverはファイルの平行移動後に定規を解決し、所属の単一性、全束収納、レイヤー連続性を検証する。ファイル収納中の定規内部は再配置せず、既存のファイル固定処理を優先する。
- 自由配置はカードの現座標が唯一の位置情報。定規移動時だけ沿線距離の差分を適用。向き変更では以前の軸から新軸へ始端距離を写す。
- 均等：g=(長辺−カード長の合計)/(n−1)。順にgを空ける。中心前進4未満ならその部分から後方へ押し出す。
- 中心均等：中心間隔=(長辺−(先頭長＋末尾長)/2)/(n−1)、下限4。1枚は始端、0枚は計算なし。
- サイズ・位置は机上単位と小数のまま。現在ズームやカメラから配置結果を導かない。
- SVGパターン1個と固定本数の目盛りパスを繰り返し、定規の長さに応じてDOM数を増やさない。素材はアクリル・竹・ステンレス。測定精度や実寸単位を提供するものではない。
- 定規自体は線・ピンの接続アンカーを持たない。所属カードの既存アンカーは維持する。

検証：配置・極端な長さ・独立した両側・方向変更・Undo・所属競合・ロック・ファイル収納・保存・コピーの単体試験。操作UIと実ドラッグ、素材描画、既存のクリップ・ファイルのブラウザ回帰試験。
