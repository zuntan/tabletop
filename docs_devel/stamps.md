# ハンコ — 選んで、ポン

対象は `type: text` と `type: file`（クリアファイル）。1パーツに1つの付属表示です。タスク状態・編集権限は変更しません。

ツールバーの「ハンコ」から印面を選びます。「日付付き」を選ぶと押印時点のローカル日付 `YYYY.MM.DD` を追加文字列に入れます。パレット右下の「取り消し」で消します。複数選択ではテキストだけを対象に、一回のUndoで処理します。任意文字列・角度の人間向け編集欄は設けません。

通常は本文枠の中央へ大きく表示し、人間の選択中は右下へ縮小します。AIの指差しでは縮小しません。移動・サイズ変更に追従します。吹き出しの先端は寸法基準に含めません。

## 保存とAI操作

```json
{"stamp":{"designId":"done_ja","text":"2026.10.20","angle":-5}}
```

`desk_execute` の既存の追加／更新で指定し、`stamp: null` で解除します。種類一覧は `desk_stamp_patterns`。押印・解除専用MCPツールは追加しません。日付は単なる文字列であり、任意の文字でも有効です（最大10000文字）。長い追加文字列は印面内に横方向へ縮めて表示します。

角度はSVG座標の度数。左下がりは負の値です。人間の押印時には日曜−3°から土曜−9°まで曜日で決定して保存します。再描画・翌日・再読込で再計算しません。AIは−360〜360°で変更できます。

## 印面

- `done_ja` 済、`rejected_ja` 却下、`sealed_ja` 封印：丸い二重枠の朱印。
- `done_en` DONE、`rejected_en` REJECTED、`sealed_en` SEALED：横長の角枠のゴム印。
- `hanamaru_ja` はなまる：丸みのある五角形風の花びらと、中央のうずまき。
- `smile_ja` ニコニコ：オリジナルの花形の輪郭と笑顔。
- `well_done_ja` よくできました：顔を付けず、大きな「たいへんよくできました」の文字を桜の花びら風の縁取りで飾る。

- `on_hold_ja` 保留、`on_hold_en` ON HOLD：済／DONEと共通の印面。
- `handle_with_care_ja` 取扱注意、`handle_with_care_en` HANDLE WITH CARE：両手で箱を支える正方形の印。英語版はメニューからのみ非表示で、保存済みの印影とAI操作は有効。
- `nandeyanen_ja` なんでやねん、`shirangana_ja` しらんがな：丸枠・角枠に大きな記号と白縁の文字。
- `keep_going_ja` がんばりましょう：よくできましたと同じ桜飾り、中央は励ましの2行。

AI向けは計16種類、人間向けパレットは15種類。パレットは4列×4段、16番目に文字サイズに合わせた「取り消し」を右下寄せで配置。はなまるの花びらの雰囲気の参考：https://www.creema.jp/item/16321314/detail （商品画像そのものは同梱しない）。

朱色・不透明度90%はパターン側に持ち、個別データには含めません。見た目の調整余地を残します。

未知IDはエラーにせず、内部の基本文字なし丸印へ表示だけフォールバックします。元ID・文字列・角度は保存・コピー・Undoで保持します。内部印は人間向け一覧には出さず、AI向け一覧には代替表示の説明として通知します。

まれに逆さまになる悪戯案は今回は不採用。将来のお遊び候補として保留します。採用時はテストで確実に再現できる入口も検討します。

## 本体ボタンで繰り返し適用（2026-10-31）

ツールバーは本体と▼を分離する。▼だけが選択メニューを開き、本体は直前に適用した設定を現在の選択へ適用する。ハンコの初期値は「済」。日付付き指定はブラウザのlocalStorageから復元し、保存がなければ日付なし。シールの初期値は列1・赤丸。未選択／対応対象なしでは本体を無効にする。
ハンコは種類と日付付きの指定を記憶し、日付は押した時点で生成する。シールは形・色・追加先列を記憶する。ホバー見本、色や形の変更だけ、取り消し／全消しは直前設定を変更しない。選択を替えて連続適用でき、通常の共有Undoに従う。
直前の図案の記憶はタブ内の一時状態で、保存データには含めない。再読込で図案は初期値へ戻る。日付付きチェックは下記のとおりブラウザへ保存する。ボタンは押下中だけ少し沈む。

ハンコ適用後は画面を即時再描画し、描画後から約1600msだけ選択中も通常の中央・大サイズで表示する。その後は選択中の右下縮小表示へ戻す。選択を解除したりカメラを動かしたりしない。対象IDとタイマーは画面側の一時状態で、保存・Undo・PDFには含めない。繰り返し押すと直近の適用対象と表示時間を更新する。取り消しでは拡大表示を解除する。

ハンコ・シール・リアクションの適用では、カード本文や無関係なオブジェクトを再生成せず、対象の装飾と状態表示だけを更新する。ハンコの拡大タイマーは二回の描画フレームを待ってから開始し、全体描画の待ち時間で表示時間が消費されないようにする。

「日付付き」のチェック状態は `tabletop.stamp.dated` としてブラウザのlocalStorageに保存し、同じサイトの再読込・再起動で復元する。机データには含めない。ストレージが使えない場合も、タブ内の操作は継続する。直前の図案など他の一時設定は永続化しない。

## 日付の配置調整（2026-10-31）

追加図案の丸形は日付を少し上へ移し、内枠との間を空ける。横長図案は区切り線を上げ、日付を下枠の内側へ収めて文字を少し大きくする。日付なしの図案は維持する。
ハナマル・ニコニコ・よくできました・がんばりましょうは、図案の下へ独立した日付を添える。図案の縦横比を保ち、日付込みで従来の表示範囲に収める。選択時の縮小表示・見本・PDFも同じ描画を使う。保存済みの図案IDや日付文字列は変更しない。

「合格」「不合格」は同じ文字サイズ53（図案内部の座標単位）へ拡大し、2文字・3文字で文字寸法が変わらないようにする。
