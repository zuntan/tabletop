# 未確定テキストのMarkdownプレビュー

テキストパーツをダブルクリックして開く編集欄に目のアイコンの「プレビュー」ボタンを置く。押している間だけ、未確定の文字列をMarkdownとして入力欄と同じ位置・寸法に表示する。ボタンを離せば元の入力欄へフォーカスを戻す。ウィンドウ切替などで解除した場合はフォーカスを奪わない。入力値や机上の本文を変更・確定せず、Undo・revisionにも影響しない。

目的はMarkdownの書法確認。カードの寸法・色・文字サイズを再現する機能ではない。背景・枠・文字色は入力欄から取得し、ライト／ダークに対応。プレビュー自体はスクロールしない。下が切れる場合は入力欄を大きくしてから再度押す。

描画は机と共通の安全なMarkdownパーサーを利用し、HTML・画像・テーブルは無効。プレビュー内リンクも操作できない。マウス／タッチの押下に加え、ボタンにフォーカスしてSpace／Enterを押し続けても確認できる。指・ボタンを離す、ポインター操作のキャンセル、フォーカス喪失、ウィンドウ切替、編集終了で解除。

「Enterで改行」の切替は既存の `tabletop.editor.submit-key` localStorage値（`enter` / `mod-enter`）を継続利用する。机の保存ファイルには含めず、同じブラウザ・同じオリジンで次回も復元する。ストレージが使えない場合は、その起動中だけ記憶する。

## 確定済みカードとの共通部分・相違点（2026-11-03）

`src/markdown.ts` と `src/main.ts` を確認。単独テキストカードは左上からMarkdownを描画する。見出し・段落・改行・強調・取り消し線・リスト・引用・コード・HTTP(S)リンクに対応し、生HTML・画像埋め込み・表は無効。通常のURL文字列を自動でリンク化する設定は無効で、相対URLもリンク対象にしない。図形内の中央文字はプレーンテキストとして扱う。

確定済みカード内のリンクは別タブで開き、`noopener noreferrer` を付ける。リンク操作から通常の選択・移動を開始しない。一方、一時プレビュー内のリンクは前述のとおり操作できない。

カードは `textColor`・`fill`・`stroke` を独立して持ち、描画領域外の本文はクリップする。内側余白は固定6ではなく `padding` で設定でき、省略時が6机上単位。角丸と文章の必要高さの測定については[テキストの枠と測定](text-measure.md)を参照。人間向けの測定ボタンは現在非表示であり、旧authoring資料のボタン説明を現行UIの案内には使わない。
