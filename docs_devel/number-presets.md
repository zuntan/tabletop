# 数値入力の候補

2026-10-19。微妙な差の候補を増やさず、よく使う値をマウスで選べる小さな「候補」ボタンを数値欄の横に追加。色選択UIに合わせた白い角丸パレットに数値を並べ、現在の候補を強調する。文字色は周囲のUIに合わせた灰色。ピン設定の既存selectも文字色を揃える。直接入力は残し、保存形式・許容値・既定値は変更しない。

パレットは選択、外側クリック、Escapeで閉じる。選択とEscapeでは元のボタンへフォーカスを戻す。スクロールやリサイズ時にも閉じ、画面外にはみ出さない位置へ表示する。

| 項目 | 候補の表示順 |
| --- | --- |
| 線幅 | 1・2・4・8・16 |
| 文字サイズ | 12・16・24・32・48 |
| 塗り透過率（%） | 100・90・70・50・30 |
| 角丸 | 0・4・8・16・24 |
| 内側余白 | 0・8・16・24・32 |

透過率は100が透明。0も直接入力できる。角丸0は角丸なし。候補外の1.5や余白30などもそのまま保持する。

作成時の線幅・塗り透過、個別プロパティの5項目、ピンシリーズの該当項目、糸の線幅・透過に適用。新しい設定項目や数値の制限は追加しない。

候補は選択時に即時反映する。個別プロパティの「変更を適用」は廃止し、直接入力は入力確定で反映する。無効な数値欄の候補も無効にする。[入力確定の規則](./property-editing.md)。

ピン設定の2列配置は、名前／表示、書式／形、幅／高さ、文字サイズ／枠を文字にあわせる、線幅／塗り透過の順。関係する項目を同じ段に揃える。

透過率の表示とパレット見出しは「塗り透過（%）」に統一（糸の欄も同じ）。糸の線幅パレットも「線幅」とする。ピンの色設定・「次：…」の案内を先に置き、その下へ糸の設定枠を配置する。

糸の線種も同じ仕組みのパレットで、実線・破線・点線を見本と文字で選ぶ。閉じたボタンにも現在の見本と名前を表示し、UndoやAIによる変更に追従する。

線・矢印の個別プロパティでは、対象外の塗り透過・文字サイズ・テキストを隠す。線幅は候補選択で即時反映し、直接入力は入力確定（フォーカス移動等）で反映する。線・矢印の両方で保存値と描画属性をブラウザ検証する。色選択の表記は図形と同じ「輪郭」に統一する。

ツールバーの線幅は新規作成の初期値と、選択中の線・図形・テキスト枠へ同時に適用する。選択中のピンはシリーズ全体の線幅へ反映する。表示値は新規作成の初期値。
