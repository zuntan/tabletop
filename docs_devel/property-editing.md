# プロパティの入力確定

2026-10-19。「変更を適用」を廃止。ボタンより上／下の位置やパーツ種別による確定方法の例外をなくす。

- 色・候補・線種・端点形状：選択時に反映。
- 数値の直接入力：Enterまたは入力欄を離れた時に反映。
- 文章・URL：入力欄を離れた時に反映。文章のEnterは改行。
- Escape：その欄の未確定入力を取り消す。
- 日本語の変換中は確定しない。

一つの欄の一回の確定を、一回のUndoで戻す。入力中の一文字ごとには履歴を作らず、Enter後のフォーカス移動でも二重確定しない。ほかの欄の未確定入力は一緒に適用しない。

空欄・不完全な数値・範囲外・無効なURLは文書へ入れず、確定時に直前の有効な値へ戻してメッセージを出す。座標欄を変えた場合のBinding解除は従来どおり。

同じパーツへの無関係な編集では入力途中の値を保持する。同じ欄が外部から変更された場合は古い入力を上書きせず、最新値へ戻して知らせる。選択が切り替わった後に、古い入力を別のパーツへ適用しない。

実装はsrc/property-editor.tsへ集約。保存形式・MCP Schemaの変更はなく、反映にMCPの再起動は不要。
