# カメラ — 撮影範囲をPNGコピー

2026-10-29実装。下段のロック右隣に「カメラ」。選択あり／なしで入口を分けず、撮影用の一時枠を調整してコピーする。

- 選択あり：選択対象全体の外接矩形を初期値にする。
- 未選択：そのタブで前回コピーに成功した範囲を初期値にする。初回は机上をドラッグして指定する。
- 枠の内側で移動、四隅でリサイズ。枠外からドラッグすると範囲を描き直す。
- 右下の「コピー」またはEnterでPNGをコピー。キャンセル／Escapeで閉じる。
- コピー失敗時はステータス欄で通知し、枠を保持して再試行できる。
- 選択、机データ、履歴は変えない。撮影枠は保存せず、前回範囲は机上座標でタブ内に保持。別の机をロードすると記憶を破棄する。
- 範囲が画面外なら、枠を操作できるようカメラを合わせる。撮影中の通常の机操作・AIの変更／カメラ操作は止め、参照と保存は可能。

## 描画

PDFと共有する`deskSceneRaster`で、背景・重なり・型抜き・ハンコ等を合成。選択中のハンコも通常の大きな状態へ戻して撮る。選択枠、操作ハンドル、AI指差し、移動マーカー、リンク操作ボタンなどは除外。撮影範囲内の全表示内容を対象とし、選択オブジェクトだけを抽出する機能ではない。

ズーム率に依存せず1机上単位＝1pxを基本とし、最大辺8192px・1600万画素の両方に収めるため必要時だけ等比縮小。PNG形式でブラウザのClipboard APIへ渡す。非対応ブラウザや権限拒否はステータス通知。

既存ラスタ処理と同様、Web資料のiframe本文は撮れず、代替表示となる。その旨をコピー成功時に通知する。外部画像はCORS等で取得できなければ失敗として再試行可能にする。生成途中に机のrevisionが変わった場合は失敗する。

カメラアイコンは本機能用の自作SVG。AI用撮影ツールの追加は今回の範囲外。
