# 論理型抜き

2026-10-21 合意。主用途は新聞の切り抜きのようなラスタ画像の部分表示。
対象はtext/image/svg/mermaid/web。型は既存の閉じた図形8種。図形同士は対象外。
型と対象を二つ選び、型の輪郭をコピーして対象の独立した表示範囲にする。
元の型は残し、移動・変形・削除しても結果に影響しない。

## 表示と保存

対象の種類・元データ・操作を保つ。画像やWebのタイトル帯と操作ボタンは切り抜かない。
型全体の矩形を結果の本文表示枠にし、元の内容の配置とレイアウト寸法を別に内包する。
画像の実画素の透明度や輪郭同士の交差は調べない。対象本文矩形と型矩形が幅・高さとも正に重なれば適用。
重なりなしは変更せず既存の赤字ステータスだけ。ダイアログなし。
輪郭内に何も見えなくても、非ゼロの表示枠と一覧から選択・OFFできる。

一対象一型。型抜き済みへの再適用は元の内容に新しい型を適用し、前の型を置き換える。
ON/OFFは型データを保持。OFF時は現在の移動・拡縮を反映した元の全体を表示。
リサイズは型枠と中身を一緒に拡縮し、テキストを型の幅で折り返し直さない。
選択枠・接続アンカーは現在の外枠。移動・クリップ・コピー・保存・Undoに対応。
人間向けの輪郭直接再編集UI・重ね掛け・合成・参照管理は設けない。回転は現在未対応、将来未定。

## 実装

feat/logical-cutoutブランチ。対象属性cutoutにenabled、正規化した輪郭path、
表示窓に対する元内容の相対位置・大きさsource、元レイアウト寸法layoutを保存する。
SVG clipPathで内容だけを切り抜く。画像再生成なし。
Webは既存sandbox iframeをクリップし、ブラウザで描画を確認済み。
MCPはdesk_executeの属性変更と型抜き操作、desk_get/contextから型抜き状態を認識できる。

## 使用方法

画像ツールの隣の「型抜き」ボタン。対象一つ＋閉じた図形一つを選択すると有効になる。
適用後も元の型は残るので、型をどけて結果を見る。型抜き対象だけを選ぶと、
プロパティ欄に「型抜き設定あり」とON/OFFボタンを表示する。
型抜きの存在をMCPからもcutout属性で取得できる。

MCPのdesk_executeでは `{kind:"cutout",id:"対象ID",moldId:"型ID"}` を使用。
ON/OFFは取得したcutout全体のenabledだけを変えてupdateする。幾何は自動で切り替わる。
cutout:nullで元全体に戻して設定自体を解除することも可能（人間用はON/OFFのみ）。
保存には原データとcutoutを保持。切り抜きPNGの生成は不要。
別タブ表示は従来どおり元の画像／SVG／Mermaidを開く。机上の型抜きは表示属性。
型抜きテキストは通常の矩形の文字収まり計測の対象外とし、誤った必要高さを返さない。
画像のimageGeometryはON時status:clipped、renderedRect:null。表示窓と原画像寸法は取得できる。

## 確認

単体：移動・拡縮後のON/OFF、元の型からの独立、再型抜き、タイトルのみの重なり拒否、解除。
ブラウザ：SVG・テキスト・Mermaid・Web iframeのclipPath表示、タイトルと操作部の保持、
コピー・保存復元・ハンコ・ラスタ化。Webはsandbox iframeを残したまま輪郭で切り抜ける。

## 外部への画像コピー

型抜きONの対象を一つ選択すると、プロパティの型抜き状態の横に「画像コピー」が出る。
クリップボードへimage/pngだけを書き込む。タイトル帯・外枠・操作ボタン・リアクション・選択枠は含めず、
輪郭で切り抜いた中身だけを透過PNGにする。追加ショートカットなし。
通常のCtrl+C／机内コピーは従来どおり、編集可能なパーツと型抜きデータをコピーする。
画像・SVG・Mermaid・テキストで共通。Webページ内容のラスタ化は未対応なのでWeb資料では無効。
ズーム倍率と独立に原則2px/world unit、一辺4096px・約800万画素を上限として必要に応じ縮小。
ブラウザが画像のクリップボード書き込みに対応し、許可する必要がある。
失敗時は既存ステータス欄で知らせる。元テキストなどへの暗黙の代替はしない。

## 操作確認済み（2026-10-21）

利用者が菱形による型抜き、ON/OFF、PNG画像コピーと机への貼り付けを確認。
貼り付けたPNGは760×400px、タイトルを含まず角の透過を保持し、型抜き属性なしの独立画像となった。
元の対象は型抜き属性と元データを保持。専用の範囲選択UIを増やさず、図形の通常操作で扱える。

AIは通常のdesk_get/context/executeで型抜き状態と輪郭を取得・変更可能。
内包pathは既存8図形だけに限定せず、段違いや凹みのある一つの閉じた輪郭にもできる。
輪郭のみの変更では表示枠を自動再計算しないため、必要なら外接矩形とsourceも同時に計算して更新する。
新聞記事の内容を考慮した切り抜きなどは利用案であり、専用の自動記事認識機能は実装していない。
