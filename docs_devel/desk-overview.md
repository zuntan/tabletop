# 画面外の方向表示と簡易マップ

2026-10-30。広大な机で、遠くに置かれたオブジェクトの存在に気づくための補助表示。

## ステータスの注意表示

実倍率が10%未満で、表示範囲から完全に外れたオブジェクトがあれば、ステータス文（通常はオブジェクト数）の横へ「画面外：← ↑ → ↓」の該当方向を表示する。文字は濃い橙色（ダークテーマでは明るい橙色）。点滅・机上への重ね表示は行わない。10%以上、または該当なしなら隠す。

対象はカード、図形、画像、線、ピン、小物、コンテナなど、表示中の全オブジェクト。一部が見えているものは方向表示に数えない。斜めの対象は2方向に現れる。線は端点から矩形を求め、その他は外枠を使う。装飾・リアクション・吹き出しの尾は範囲へ加えない。非表示のピンは除外する。

## 出し入れできる簡易マップ

机の左上の二重矩形ボタンで開閉する。倍率による制限はない。開閉状態はブラウザの `tabletop.overview.open` に保持し、机ファイルには含めない。

164×112pxの地図に、机上全体の外接矩形（半透明の青）と現在の表示範囲（半透明の橙）の2つだけを描く。重なりは混色で分かる。細い輪郭線と凡例も付ける。個別オブジェクトのミニチュアは描かない。

どちらか大きい方を基準とするのではなく、両矩形を含む範囲を地図内へ収める。片方が画面外にはみ出す場合や、縦横で大小が逆でも位置関係を保つ。空の机では表示範囲だけを示す。地図は参照用で、クリックやドラッグによる視点移動は初版には設けない。

## 更新と性能

オブジェクトの矩形と全体の外接矩形はシーン更新時にキャッシュする。パン・ズームではキャッシュとカメラの数値を使い、個別オブジェクトのDOM測定は行わない。更新をrequestAnimationFrameで集約し、閉じた地図のSVG更新は省く。方向走査は10%未満のみで、4方向がそろった時点で打ち切る。

本環境の座標計算だけの参考測定では、1万矩形に対して方向判定と2矩形の投影を500回実行し、合計69.2ms（1回平均0.138ms）だった。DOM描画や既存の机描画は含まないため、全体のフレーム時間や他の端末の応答保証ではない。

## 検証

矩形の大小が縦横で逆になる場合、離れ小島、部分的に見える対象、空の机、ゼロ面積を単体テスト。実ブラウザで5%の方向表示、10%での非表示、2矩形の描画、開閉、キーボード操作、カメラ・revision不変を確認した。既存の上部折り畳み・パレット・シール操作も回帰確認。
