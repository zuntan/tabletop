# クリアファイル

2026-10-23。配置を保ったまままとめて移動する、見える入れ物。

- 選択して「クリア／ファイル」（2行表記）ボタン。アイコンはTablerのfile-lock。保存用ファイルメニューと区別し、ツールチップは「選択を配置ごとクリアファイルにまとめる」。対象は図形・線・テキスト・画像・SVG・Mermaid・Web・リンクと、クリップの束。クリップの一部を選ぶと束全体へ広げる。
- ピン・小物・既存ファイル・既存ファイルの中身を含む選択は処理全体を拒否し、赤字ステータスで理由を表示。入れ子・ファイル同士の結合なし。
- ファイルは中身全体の外接矩形より一回り大きく、常設のタイトル帯、薄い色付き背景と二重枠。色・透過・タイトル・ハンコ・リアクションを編集できる。
- 作成時にファイル左上をグリッドへ合わせ、その差分だけ全体を平行移動。スナップOFFなら補正なし。解除時の逆補正なし。
- ファイルが最背面、その上へ中身を元の順序で連続させる。中身の前後変更は禁止。ファイル全体の前後変更は可。
- 中身のどれをドラッグしても全体移動。個別の座標・サイズ・端点・吹き出し先端などの変更は禁止。文字や色は編集可。鍵マークは所属の表示に使わない。
- ファイル内クリップの解除・抜き差し・間隔・留め位置・サイズ変更・削除は禁止。クリップ所属の紙の削除も禁止。ファイル解除後は元のクリップの操作へ戻る。
- 通常の中身は個別削除できる。最後の中身がなくなるとファイルも消える。削除後に外枠は縮まない。
- ファイルを削除すると解除し、中身はその場に残す。ファイル本体を選んだグループ解除ショートカットも利用可。タイトルに専用解除ボタンは置かない。空ファイルの新規作成なし。
- 外部へ接続された線・ピン等は既存ルールに従い追従する。外部から中身の形を引っ張る場合は、相対配置の固定を優先する。接続の追従が固定配置と両立しない箇所は接続を外す。
- 保存・複製・Undoは束を維持。個々の世界座標とfileMembersを保存し、解除用の補正値は持たない。幾何制約は人間UIとMCPの両方へ適用。

初期の見た目：外側余白24、タイトル帯34、枠間隔6。色と濃さは通常の塗り・透過で調整でき、濃い色を禁止しない。サイズは作成時に固定し、変更したければ解除してまとめ直す。


## データと操作

`type: "file"`。`fileMembers`へ世界座標の中身IDを前後順で保存し、ファイル本体のx/y/width/height、text（タイトル）、fill/fillOpacity/stroke/strokeWidth/textColor/fontSize、stamp/reactionsを保持する。ファイル自身は接続アンカーを持たない。中身の既存アンカーは引き続き使える。

AIは既存のdesk_executeで追加・更新・削除する。中身の外接矩形に余白24と上部タイトル34を足した枠を作り、fileMembersにはクリップ全員を含める。作成時はsnap:exactで位置を保つか、ファイルと中身全体へ同じスナップ補正を適用する。移動はファイル本体のx/y更新を推奨。ファイル内の個別構造変更はAIでも拒否し、先にファイルを削除して解除する。

通常のマウスロックは別の機能で、ファイル全体へ適用する。所属の印として個々に鍵を付けるわけではない。ファイルを選んでコピーすると中身も一緒に複製され、ID・内部接続を振り直す。一覧の「クリアファイル」フィルターは中身も含めて表示する。
