# AIからのピン枠自動調整

2026-10-29追加。`desk_pin_fit`は、人間側の「枠を文字にあわせる」と同じブラウザ内の計測・計算処理を実行する。AIが幅と高さを推測・再計算して書く必要はない。

```json
{"deskId":"対象の接続ID","seriesIds":["series-a","series-b"],"expectedRevision":42}
```

- `seriesIds`は1〜200件。重複は除外し、全シリーズを先に検証する。不明IDが1件でもあれば変更しない。
- 現在の文字サイズ・形状を使い、シリーズ内の現在の表示文字と次の番号を計測する。空シリーズでも次の番号を使う。
- 複数シリーズの調整は一括の履歴1件。Undoでまとめて戻せる。
- `expectedRevision`は任意。競合時は実行しない。`actor`も通常の編集と同様に指定可能。
- 戻り値の`frames`に各`seriesId`、調整後`width`・`height`を返す。
- 文字サイズ自体は変えない。必要なら先に`desk_execute`の`series_update`で変更する。
- 人間の選択や視点、取り付け先、シリーズの順番を変更しない。枠寸法に伴う位置の扱いも既存UIと同じ。取り付け済みピンは対象アンカーに追従する。
- フォント読込中は失敗として通知。人間の編集中、カメラ枠の操作中、「ひとりで考える」中はAIによる枠変更を拒否する。

実装：`pin-fit.ts`の共通処理をUIとMCPの両方から呼ぶ。プロトコルは`pin_fit`、MCP名は`desk_pin_fit`。
