# リアクション：気持ちや小さな状態の印

2026-10-30。既存の18種類へ ▶・⏸・🔁・🔍・🛠・💤 を追加し、24種類にした。意味や状態遷移は固定せず、選択欄の名称は文字の見分けのためだけに使う。感情用／状態用のカテゴリも設けない。文字・絵文字による表示で、OS・フォントにより見た目は異なる。

ハンコは全体への判断、シールは分類・程度、リアクションは途中のチェックや気持ちの印にも使える。ただし使い方は利用者に任せる。

`reactions` は従来どおり一対象に各記号1つまでの集合。複数選択では付いていない対象へ追加、全対象に付いていれば全対象から外す。旧✅・○・✕は引き続き読める。

`reactionSize` は対象単位の共通バッジ寸法（1〜100000、未指定24）。プロパティ「リアクション／大きさ」で変更でき、候補は文字サイズ候補（12・16・24・32・48・64）の2倍、24・32・48・64・96・128。ピンのサイズやシリーズ設定と独立。保存・コピー・UNDOで保持する。

通常のズーム追従へ統一した。ピン自体は画面上のサイズ固定を維持するが、付属リアクションはズーム追従。縮小して印が読めない場合は、対象のサイズ設定で調整する。バッジは操作対象やアンカーにしない。PNG/PDFは100%相当で描画。

## 配置切替（2026-10-30）

`reactionPlacement` を対象ごとに保持する。初期位置は右下から左へ並ぶ `bottom-right-left`。大きさと配置の操作はプロパティで一行に並べる。配置ボタンから、四隅ごとに横・縦の2ボタンをまとめたSVG見本で選ぶ。

| 表示 | 値 | 置く辺 |
|---|---|---|
| 左上→ | top-left-right | 上辺の外側、左から右 |
| 左上↓ | top-left-down | 左辺の外側、上から下 |
| 右上← | top-right-left | 上辺の外側、右から左 |
| 右上↓ | top-right-down | 右辺の外側、上から下 |
| 左下→ | bottom-left-right | 下辺の外側、左から右 |
| 左下↑ | bottom-left-up | 左辺の外側、下から上 |
| 右下← | bottom-right-left | 下辺の外側、右から左 |
| 右下↑ | bottom-right-up | 右辺の外側、下から上 |

一列は最大7個とし、超過分はカードから離れる側へ折り返す。大きさ・ズーム追従は従来と共通。配置変更でオブジェクトを最前面にしたり、クリップの順序・カード位置を変えたりしない。クリップの見えている縁に合わせて使う。

配置とサイズはピンの場合もシリーズと独立した個別属性。通常コピー／机間コピー・保存・UNDOで保持する。ピンのコピーでは、反応をまだ付けていない場合も設定を維持する。PNG/PDFも同じ配置を使う。

旧データで配置が未指定なら下側の表示を維持する。右起点は印の並びが右→左になるため、従来の下側グループ内の左右順とは異なる。印自体は順序を編集するデータではなく、従来どおり種類ごとの集合。
