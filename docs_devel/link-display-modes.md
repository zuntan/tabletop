# リンクカードのURL文字・QR表示

2026-10-28／実装・利用者確認待ち。QRカードと同じ `feat/qr-cards` ブランチで作業。

タイトルだけでは面積の割にリンクが机へ埋もれるため、通常HTTP(S)リンクに2つの表示方式を設ける。プロパティの二択ボタン「URL文字／QRコード」で切り替える。「最小」は独立モードにせず、矩形の調整で扱う。

## 見た目

- 上部は鎖アイコン、タイトル、既存の「開く」。QR表示でも鎖を残し、任意文字列の独立QRカードと区別する。
- URL文字：角丸矩形の白い枠。本文領域にURLを左寄せで表示し、長いURLは幅で折り返す。本文にも文字と同じ大きさの鎖を添える。文字サイズ・文字色・角丸は既存の設定欄を利用。
- QRコード：タイトル下へ、白背景・余白付き正方形のQRを中央表示。専用QRと同じ標準設定と容量超過表示を再利用。QR表示中は文字サイズ欄を隠し、文字用の設定値自体は保持する。
- 枠が小さい場合は見える範囲に収め、入力やURLを切り詰めない。QRの比率は保ち、見せる大きさは利用者が矩形で調整する。

## データ・操作

通常の `type:link` に任意の `linkDisplay:url|qr` を保持。省略時・既存データはurl表示。URLは既存の `url` 1か所だけで、`qrText` や生成SVGを保存しない。タイトルは `text`。`fontSize`・`textColor`・`cornerRadius` はURL文字の書式として公開し、書式スポイトでも扱う。表示方式自体は書式へ混ぜない。

表示切り替えはURL、位置、寸法、文字書式を変えずUndo対象とする。コピー・保存・ロードで表示方式を維持。外部コピーは従来どおりタイトルとURL。リンク先を変更すると開く先と文字・QRが同時に変わる。新規の初期寸法は画像等と同じ368×226。既存リンクの寸法を自動変更しない。

机ファイルを参照する `deskPath` のリンクは対象外。従来の机イラストと操作を維持し、表示切り替え設定は受け付けない。

AIは既存のget/executeで `linkDisplay` を読み書きする。QR表示のリンクは `desk_asset_read` で生成SVGを取得でき、そのときの `qrText` メタデータはURLの派生値。専用QRと同じ内部 `qr_render` を使う。MCP側の新しい属性とasset_readの反映には再起動が必要。

## 検証

旧リンクの既定表示、切替時のURL・矩形・書式維持、保存・コピー・Undo、机リンクの除外、QRのURL参照を単体テストで確認。ブラウザで二択ボタン、本文の左寄せと折り返し、鎖のサイズ、URL変更、QR生成と取得、机リンクの見た目を確認。URL・QR両表示のPDF出力も確認済み。単体268件は全件通過。

URL文字表示は角丸矩形と同様に塗り・透明度・輪郭色・線幅・角丸を設定でき、書式スポイトにも含む。QR表示では背景を白に固定し、これらの設定を保持したまま無視する。

シールがあるQR（独立QR・リンクのQR）は上下にシール1枚の直径分の余白を取り、外枠を変えずQR表示領域を狭める。折り返した列数は考慮しない。ズーム固定シールは画面上の直径に追従する。
