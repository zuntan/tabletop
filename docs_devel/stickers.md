# シール：貼る、並ぶ、全部剥がす

2026-10-30：シール列2と右下初期値を追加。初版2026-10-22。親に付属する単色のSVGシール。独立オブジェクト・座標・アンカー・選択状態は持たない。

## 属性と操作

対象はテキスト・8種の図形・画像・SVG・Mermaid・Web・リンク。線・ピン・クリップ・小物は対象外。

`stickers`属性を持つ。例：`{items:[{color:"#ef4444",shape:"circle"},{color:"#3b82f6",shape:"star"}],items2:[{color:"#22c55e",shape:"star"}],origin:"bottom-right",diameter:36,fixed:false}`。

- items：シール列1の追加順の {color, shape} 配列。同じ色・形の重複、形の混在可。shape は末尾のID一覧を参照
- items2：シール列2の追加順配列。省略時は空。2列固定で命名・列追加は設けない
- 旧 colors 配列は読み込み時に circle の items へ移行。両方の同時指定は不可
- origin：top-left／top-right／bottom-left／bottom-right。既定は右下。既存の明示された起点は維持する
- diameter：共通直径、1〜100000。既定36。候補24・36・48・64・80・100
- fixed：画面上の直径を固定するか。既定false

プロパティには色・形・追加・全消しを2段置き、「シール列1・シール列2」とする。起点・直径・ズーム固定は共通。色は既存カラーパレットを再利用する。現在の列の一覧・縮小見本・個別編集は置かない。複数選択は対応対象それぞれへ追加／全消し／設定変更。対象外が混ざっても変更しない。

「追加」は操作したシール列の末尾へ1枚。全消しはその列だけ空にし、起点等の設定は残す。個別削除・並べ替え・ドラッグなし。色・形の選択は次に追加するシールであり、既存のシールを変更しない。

表示時はitems→items2を連結し、従来どおり一続きに配置する。「シール列」は操作・データの単位で、表示上の段ではない。分類／程度などの意味は利用者に任せる。旧データのitemsは列1、列2は空としてそのまま読める。

## 配置と折り返し

親の表示矩形（本文枠・メディアのタイトルも含む外枠。吹き出しの尾は含めない）の四隅から横・縦それぞれ直径×1だけ内側を起点に、中心間距離を直径×1.2として水平に並べる。

左起点は右へ、右起点は左へ追加。最初のシールを起点側に残す。中心が反対側の辺から直径×1の内側を超える前に折り返し、同じ起点側から次の段を開始する。上起点は下へ、下起点は上へ段を増やす。段数・高さには制限しない。狭い対象も最低1段1枚を表示し、横の中心は対象中央へ寄せる。縦の起点も高さ不足時は中央へ寄せる。2枚目以降は横には増やさず次の段へ送る。

右下で赤→青→黄を1段に追加した場合、画面左から黄・青・赤となる。追加順の配列自体は変更しない。

fixed:trueでは、その時点の画面上の親幅に合わせて並び直す。縮小すると1段の枚数が減り、段数が増える。falseでは親と一緒に拡縮する。移動やリサイズにも追従する。回転機能は現在ないが、将来も画面上の外接矩形と水平な列を基準とする方針。

## 保存・描画・連携

モデルで色・直径・起点・対象種類を検証し、公開属性・机ファイル・机内コピー・Undoで保持する。親の削除で一緒に消える。設定の削除にはstickers:nullも使用可能。AIは既存desk_get／desk_executeを利用し、items／items2配列は現在値を読み、expectedRevisionで競合を避けて更新する。専用ツールは追加しない。

SVGの親グループ内に操作対象外のSVGアイコンを描く。型抜きでは原本内に重ねず、表示窓の外枠へ一度だけ描く。PDFは100%相当の表示でシールを再配置し、現在のカメラに依存させない。通常のパーツラスタ化・BHは表示中のシールを含め、型抜きの「画像コピー」は従来どおり中身だけを取得する。

シールを選択枠・ヒット領域・接続アンカーには加えない。オブジェクトの枚数も増えない。反応バッジ等と重なる可能性はあるが、自動回避や専用レイアウト機能は増やさない。

リアクションは気持ちや小さな状態の印、ハンコは判断、シールは小さな分類・進捗・評価。自由配置が必要なら既存の図形を使う。形は1枚単位で保持し、直径・起点・ズーム固定は対象単位で共有する。

## SVG図案と選択

形は独立した［▼］ボタンから選択。色ボタンの見本も選択形状へ変わる。選択・色見本・机上に同じSVGを使い、実輪郭の外接矩形で余白を取り除いて縦横比を保ち、指定直径の正方形内へ収める。

ID一覧：circle / star / triangle / diamond / alert-square-rounded / heart / seedling / michelin-star / award / trophy / mood-smile / paw / pig / confetti / ghost。

diamond の図案は square-rotated。データIDは既存互換のため diamond を維持する。Tabler Icons の Filled版をローカル同梱し、描画時のネット接続やフォントに依存しない。出典とMITライセンスは src/assets/stickers/README.md と LICENSE。

シールは書式スポイト・適用にも含む。列の色・形・順序と共通設定をまとめて記憶し、貼付・新規作成にも使う。詳細は[書式スポイト・適用](format-styles.md)。
