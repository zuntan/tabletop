# AIの操作調整・指差し・カメラ

2026-11-03。旧ai-interface資料を現行実装と照合して移管。全ての机別ツールにはdeskIdを指定する。以下の操作は、人間と共有する画面を扱う。

## ひとりで考える

人間だけが切り替えるタブ内のモード。ONではAIによる文書変更・読込・Undo／Redo・選択・指差し・接続解放・カメラ移動などを受信時に拒否する。actorをhumanにしても回避できない。参照・保存・画像取得・測定などは許可するため、情報を隠す機能ではない。人間の編集は止めない。

ONへの切替では既存のAI指差しを消すが、人間の選択・文書・履歴は変更しない。通常の再接続・ファイル読込で維持し、ページ再読込でOFFへ戻る。机には保存せず、MCPから切り替えるAPIはない。拒否時は解除を促したり自動再送したりせず、次の依頼を待つ。実装はsrc/thinking-mode.tsとsrc/main.ts。

## 指差しとロック

`desk_point({deskId,ids:[...]})`はAIの一時的な指差し集合を置き換える。人間の選択・文書revision・Undoを変更しない。解除はids:[]。人間の「AI指差し解除」操作、対象削除、切断でも解除され、以前の集合を自動復元しない。現在値はcontext／state／selectionのaiPointingで確認する。緑は既定の枠色で、机の設定によって変更できる。

単に対象を示す用途で、人間の選択を変更するdesk_selectを代用しない。編集には対象IDを指定できるため、指差し自体は必須ではない。

`desk_lock({deskId,locked:true|false,expectedRevision})`は指差し対象へ適用し、空集合を全体とは解釈せず拒否する。専用ツールは最大200個。直接update.patch.lockedでも変更できる。文書属性として保存・Undoの対象で、省略はfalse。同じ状態なら変更履歴を増やさない。クリップ等の束には各コンテナの共通ロック規則が作用する。

ロックは人間の幾何操作を防ぐもので、権限境界ではない。AIによる明示編集は可能。現在のキーボード移動・リサイズもロックを尊重するため、旧資料の「キーボード操作は可能」を幾何操作の説明には使わない。人間の選択・本文編集・プロパティ操作・削除の可否は、収納中の制約など各道具の規則も適用する。[キーボード幾何操作](keyboard-geometry.md)、[クリップ](clip-bundles.md)、[クリアファイル](clear-files.md)を参照。

## 表示範囲の取得と移動

`desk_camera_get({deskId})`はcenter（机上の中心）、zoom（1=100%）、viewport（CSS px）、visibleBounds（机上矩形）を返す。UIの重なりによる遮蔽は差し引かない。参照だけで選択や文書を変えず、編集中・ひとりモード中も取得できる。

`desk_point`の後の`desk_fit({deskId})`は指差し範囲を余白付きで表示し、指差しが空なら机全体。人間の選択は参照・変更しない。指差すだけでは移動しない。空の机ではカメラを変えない。

`desk_camera_move`はcenterまたはpan、zoomまたはzoomByを指定する。それぞれの組は同時指定不可で、少なくとも一つ必要。panは机上単位で見る位置を動かすため、正のxなら物体が画面上で左へ流れる。倍率だけなら画面中央の机上位置を保つ。座標の各軸は±2,000,000、絶対倍率0.05〜8、相対倍率0.01〜100。相対指定で表示限界を超えた場合は制限し、zoomClampedを返す。

fit／camera_moveはdurationMsを0〜2000で指定でき、省略時は距離・倍率差から250〜900ms、0なら瞬時。ブラウザ内のD3補間でパンと倍率を連動し、遠距離では途中で引く。完了後に応答し、移動中のcamera_getは現在フレームを返す。表示だけの変更で、文書・保存・Undoには含めない。

人間の編集・ジェスチャー・ひとりモード中やスクロール直後は移動を拒否する。wheel／scrollの最終入力から400msは新しいAIカメラ操作を受け付けず、保留もしない。入力・非表示化・切断・後続命令等で実行中の補間を中断し、その時点の表示に留める。自動再開・再送はしない。動きを減らす設定では瞬時に適用する。

実装参照：src/camera-control.ts、camera-animation.ts、camera-activity.ts、focus-camera.ts、main.ts。パーツの[移動演出](object-move-easing.md)は実装済みの別機能で、カメラの[経路移動](wayfinder.md)とも区別する。共通の配置規則は[スナップ](shared-snap.md)を参照。
