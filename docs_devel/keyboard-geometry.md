# キーボードによる移動・リサイズ

- 矢印キー：選択オブジェクトを移動。複数選択にも対応。
- Shift＋矢印キー：単体の矩形を、左上を固定して右下方向にリサイズ。
- スナップONでは実スナップ間隔（グリッド間隔÷スナップ間隔の比率）を使用。サイズはその倍数へ進め、最小値も実スナップ間隔とする。モデル固有の最小サイズがあればそちらを優先。
- Altを併用するとスナップを一時的に無視し、1机座標単位で操作。最小サイズも通常の制約へ戻る。
- スナップOFFも1机座標単位。ズーム倍率には依存しない。
- サイズ非スナップで作成した道しるべ・通常選択の小物も手動リサイズの対象。
- ピン・クリップ・クリアファイル・定規・線はキーボードリサイズの対象外。ヘッド選択の小物、クリアファイル収納中のもの、ロック中のものにも既存制約を適用。
- 移動は既存のコンテナ・線の接続処理を再利用。近傍にある別の物体へ自動接続する処理は行わない。
- 押している間は接続解決を含む差分プレビューだけを更新し、机全体の複製・確定・履歴作成・全体再描画を繰り返さない。キーを離したときに一括確定し、一度のUndoで戻す。
- マウス操作の開始、別のキー操作、画面からフォーカスを外した場合も、その直前までのプレビューを確定する。編集中はマウスドラッグと同様、MCPへの編集要求を保留せずエラーとして返す。
- 文字入力欄、選択欄、ボタン、インライン編集、描画・撮影・確認ダイアログ中には適用しない。

新規作成時のサイズスナップと、手動リサイズの対象制限は独立している。

確定時も変更箇所だけを描画し直し、オブジェクト一覧・無関係なメディア・ハンコを作り直さない。
内部のキーボード確定処理は幾何更新だけに限定し、変更していない検証済みオブジェクトを再利用する。
通常のMCP編集・保存データの公開コピー・Undo履歴の独立性は維持する。
