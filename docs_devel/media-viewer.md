# 画像・SVG・Mermaidを別タブで見る

カード右上の矢印から画像本体を別タブで開く。画像は元のsrc、SVGは画像として、Mermaidは開いた時点の生成SVGを表示する。埋め込みデータにも対応し、公開URLを発行しない。

別タブは独立した表示で、机の後続編集には追従しない。ブラウザ表示領域に収まるよう縮小する。開く操作は選択・移動・ピン配置・編集を起こさず、履歴やrevisionも変更しない。Enterでも開ける。

画像・SVGに任意のリンク先URLが設定されている場合は、従来のリンク矢印を右端に残し、その左へ画像本体の矢印を追加する。ツールチップは「別タブで開く」と「画像を別タブで開く」で区別する。

別タブはユーザー操作の同期処理で開き、openerを切り離す。SVGを実行可能なHTMLとして挿入せず、常にimg要素の画像として表示する。Mermaid生成失敗時は、開いたタブへエラーを表示する。ポップアップがブラウザに拒否された場合は机を変更しない。
