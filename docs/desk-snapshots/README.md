# 資料用の棚スナップショット

開発の節目に棚の状態を残し、後日その時点の棚を開いてスクリーンショットや説明資料に使うための記録です。毎回の編集や自動保存では更新しません。

## 運用

- `YYYY-MM-DD-NN.tabletop` の日付・連番付きで追加し、以前のファイルは上書きしません。
- 名前・配置・文章などはその時点の棚のまま保持します。古い「未実装」等の表記を現在の実装状況に合わせて書き直しません。
- 保存後に形式・件数・秘密情報の混入を点検し、元ファイルと同じ内容であることをハッシュで照合します。
- 本体の変更とは別に、棚スナップショットだけを選んでコミットできます。スクリーンショット撮影・push・公開は別の作業です。
- 接続トークン、復帰record、公開の棚ID、sessionId、Undo履歴、カメラ位置は保存ファイルに含めません。棚の名前は保存します。

## 後日スクリーンショットを撮るとき

1. 使用中の棚を失わないよう、別のタブ／棚を開きます。現在の棚へ読み込む場合は先に保存します。
2. 対応する版のTabletopで対象の `.tabletop` を読み込みます。古いアプリでは未知の設定を拒否する場合があります。
3. 同じ資料を比較する場合は、画面サイズやズーム・表示範囲もそろえます。全体表示から始めると位置を把握しやすくなります。
4. 撮影時にはヘッダーの棚IDが新しくなることに注意してください。これは開いているタブの目印で、保存時点のIDを再現するものではありません。
