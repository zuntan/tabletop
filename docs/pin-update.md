# ピンアップデート（2026-10-18）

机の「ピンアップデート」カード（`text-9ccd7072`）に基づく実装記録です。コード・ビルド・隔離ブラウザでの関連動作テストを完了。稼働中の机へ反映し、保存復元後の124パーツと設定の一致も確認済みです。

## 呼称

画面の「ピン体系」を「ピンシリーズ」へ変更します。内部の `series`・`seriesId`、`series_add`／`series_update`／`label_add`、パーツ型 `label` は互換性のため維持します。既存のシリーズ名や机上の文章は自動で改名しません。

## 固定サイズの描画

ピンの図柄、番号、説明文をカメラ倍率によらず同じ画面上の寸法で描画します。100%表示時の寸法が基準です。各ピンの机上の基準点は保存値 `(x + width / 2, y + height)`。この下部中央を動かさず、描画時だけ逆倍率をかけます。

保存された座標・寸法・文字サイズはカメラ操作で変更しません。人間の選択枠・ロック表示・AI指差し、範囲選択、フォーカス、端点吸着も描画サイズに合わせます。ピンに結び付いた矢印等の表示上の端点も追従させます。説明文の編集欄は表示上のピン位置へ出します。

単独ピンのフォーカスでは、画面の上限倍率まで寄せ、固定寸法のピンと説明文を収めます。説明文そのものが画面より大きい場合は、カメラを引いても文字は小さくならないため、すべてを収められないことがあります。

## 表示の3段階

| 内部値 | 表示名 | 内容 |
| --- | --- | --- |
| `all` | ピンとテキスト | ピンと説明文 |
| `pins` | ピンのみ | 番号付きピンだけ |
| `hidden` | ピン非表示 | ピン・説明文・糸を非表示 |

上部の旧「ピンテキスト」ボタンは、この順に循環し、現在のモードをキャプションで表示します。全体モードは閲覧タブ内の一時状態で、Undo・保存ファイルには入れません。読込では保持し、ページ再読み込み時は `all` に戻ります。

シリーズのプロパティには `visibility` を追加。こちらは共有設定として保存・Undoに対応します。全体とシリーズのうち制限が強い方を適用します。

`hidden` > `pins` > `all`

全体 `all` は各シリーズの指定へ干渉しません。非表示のパーツも削除はせず、一覧・MCP参照には残します。キャンバスの当たり判定・選択枠・フォーカス範囲には含めません。

## 糸

シリーズの `thread` 設定を保存します。

| フィールド | 既定値 | 意味 |
| --- | --- | --- |
| `enabled` | `true` | 旧データ互換用。UIは「糸を表示」の1スイッチに統合 |
| `visible` | `true` | 糸の表示（ピン表示とは独立） |
| `color` | `#64748b` | 線の色 |
| `width` | `2` | 画面上の線幅、0〜100 |
| `opacity` | `1` | 不透明度、0〜1（UIは%） |
| `dash` | `solid` | `solid`／`dashed`／`dotted` |

最小番号から順に、ピンの下部中央を折れ線で結びます。同じ番号が複数ある場合は文書順。2本未満では描画しません。糸はシリーズのピンより下に置き、独立パーツ・独立ID・一覧項目・選択対象・Undo項目は作りません。ピンの移動・増減・採番・Undoで描画を更新します。糸の設定変更はシリーズ設定の変更として一回のUndoになります。

`series_update` で `thread` の一部だけ指定した場合は、その項目だけを既存設定へマージします。シリーズが `hidden` の場合は、糸の設定にかかわらず非表示です。

## シリーズ単位のレイヤー

同じシリーズの全ピンを一つの連続した重なり順の区間にまとめます。初期の基準位置は最も背面側のメンバー。ピン一つに最前面・最背面・`reorder` を指定すると、シリーズ全体が移動します。新しいピンもその区間へ追加されます。文書順を使うオブジェクトリストでも隣接します（フィルターでは対象外パーツは表示されません）。

糸はそのシリーズの最初のピンの直前へ描画するため、同じ区間で全ピンより下です。他のシリーズや通常パーツとの前後関係は、シリーズの区間の位置に従います。

## 保存と互換性

- `visibility` と `thread` は保存されるシリーズ設定です。旧ファイルにない項目は上の既定値で補います。
- ファイル形式はversion 1のまま。新項目を知らない旧アプリでは読み込めない場合があります。更新前のファイルは残してください。
- 新UI・サーバーを揃えて使用します。開いたままの旧UIはこのコード変更だけでは変わりません。
- 読込時にもシリーズの連続化を適用するため、以前ピン同士の間にあった通常パーツとの重なり順が整理されます。位置・本文・IDはそのままです。
