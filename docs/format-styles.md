# 書式スポイト・適用

2026-10-21。人間向けの書式道具。「現在（FORMAT-0）」と「書式1・2・3」を持ち、DEFAULT・初期値リセット・自動スポイトは設けない。

## 操作

ツールバーの線幅・塗り透過の隣に「書式」枠。下に現在の［スポイト］［適用］と小さな［▾］を直接置く。現在の文字キャプションは出さない。［▾］で保存枠1〜3だけを一段のポップオーバーに開き、それぞれスポイト／適用を置く。

- スポイト：対応する対象を単独選択し、押した枠へ書式を記憶。書式1〜3なら同じ書式を現在にも反映。
- 適用：選択対象（複数可）へ適用し、使用した書式を現在にも反映。未記憶枠は無効。
- 選択を変えるだけでは現在も保存枠も変わらない。
- SET-A（既存の色・線幅・塗り透過）は現在の一部を表示・編集する操作欄。スポイト／適用で逆反映し、SET-Aを変更したら現在と選択対象の該当項目だけ変わる。保存枠は変えない。
- 人間による新規作成・外部文字列貼り付けは現在の対応属性を使用。同じタブのオブジェクトコピーはコピー元の全属性を優先。
- 枠の用途は自由。全部を線用にしてもよい。命名・管理画面・引っ越し機能なし。

## 対象と書式

テキスト・8種の図形・線／矢印。画像・SVG・Mermaid・Web・リンクはシール書式のみ対応。ピン・クリップ・小物は対象外。混合選択への適用では非対応対象を変更しない。

色・塗り透過・輪郭・線幅・文字色・文字サイズを対象種類に応じて扱う。テキストは角丸・内側余白、角丸矩形は角丸、図形は文字サイズ調整（完全自動／縮小のみ／従来の固定）も対象。線は線種・両端形状・接合部丸めを含む。異種適用は共通の有効な属性だけを反映する。

内容・位置・寸法・接続・所属・ロック・リアクション・ハンコ・吹き出し・型抜きは含めない。線の作成ボタンは現在の端点形状を使用するが、矢印ボタンは従来どおり終点を矢印にする。

## 保持と既存設定

ブラウザlocalStorageの`tabletop.format-styles.v1`に現在と保存3枠を記憶。異常な保存値は検証して破棄する。利用できない環境ではタブ内で使用し、保存不可を通知する。

現在の共通6属性（色・線幅・文字サイズ等）は既存の共有作成設定`settings.defaults`と同期する。この部分は従来どおり机の保存・読込・Undo・MCPのdefaults_updateに従い、SET-A表示も一致する。再起動時はブラウザに記憶した共通属性を初期作成設定へ反映するが、机を読み込むとその机の共有設定が優先される。現在の追加属性と保存3枠はブラウザ内だけに保持し、机ファイルへ保存しない。

スポイトした線に文字サイズ等がない場合、現在の共通作成設定は保ったうえで、線の対応属性を取り込む。追加属性は吸った書式のものへ置き換える。保存枠の編集は明示的なスポイトだけ。机上への適用は共有Undo、ブラウザの書式記憶そのものはUndo対象外。

書式のポップオーバーはスポイトボタン（書式操作欄）の左端、ピンシリーズはピン追加ボタンの左端に揃える。画面からはみ出す場合は画面内へ収めることを優先する。

## 確認

ビルド、書式属性と記憶検証の単体2件、関連ブラウザテストが成功。単独スポイト・複数対象への適用・選択での非更新・SET-A同期・文字列貼付・机内コピーの書式保持・線の新規作成・再ロード保持を確認。利用者によるカード書式統一と最終UI配置の確認済み。

## シールの書式

シール列（色・形・順序）と、配置起点・直径・ズーム固定も現在／保存枠1〜3へ記憶する。シール対応のカード・図形・メディアへ適用でき、メディア間ではシールだけを扱う。シールなしの対象をスポイトするとnullを記憶し、適用先のシールを外す。旧保存枠でstickersがない場合はシールを変更しない。線にはシールを適用しない。新規作成や外部文字列貼付にも現在のシールを含める。机内コピーは従来どおり元のシールを保持。
