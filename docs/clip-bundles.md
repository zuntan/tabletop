# クリップでカードを束ねる（仕様）

## 目的と作業順

クリップは机上で複数のカードをまとめ、一定間隔に並べる道具。`feat/clip-bundles`で試作し、利用者の操作確認を経て2026-10-20にmainへ統合した。磁石は別の将来カードへ分離済み。

## 対象・構造

- 対象はテキスト・画像・SVG・Mermaid・Web資料・リンク。図形・線・矢印・ピン・小物・クリップは対象外。
- 1枚は1クリップにのみ所属。入れ子・二重留め・束同士の留め直しは当面禁止。
- クリップは順序付きのメンバーID、留めるアンカー、オフセット、サイズ、色、意匠を保持する。カードの内容は複製しない。
- 1枚目が束の基準。標準は左上。上下左右と四隅の8点を指定できる。
- 後続は同名アンカーを基準に、1枚目のアンカーから中心へ向かう単位方向へ、枚数分のオフセットを累積して並べる。
- オフセットは机上の距離で0以上。専用の上限は設けないが、既存の座標・寸法の許容範囲は守る。0で同寸法ならぴったり重なる。
- 変更すると即時に再配置。配置パターンはまず一つ。扇形等は将来。

## 接続

1枚目のアンカーは有効。2枚目以降は一時無効にし、接続中の線・ピン・吹き出しを外す。外された相手はその位置に残す。紙を抜けばアンカーは再び有効になるが、以前の接続は復活させない。

## Z順と一覧

背面から、1枚目→2枚目→…→クリップの連続した一群にする。リストは手前からなのでクリップが先頭になる。どのメンバーから最前面／最背面へ移しても束全体を移動。「クリップ」フィルターは例外的にクリップと全メンバーを表示し、通常のZ順は保持する。

## 操作

- Ctrl/⌘＋G：選択順の対象カードを束ねる。最初の対象が1枚目。1枚だけでも可。対象外・ロック済み・既存の束に所属するカードは無視。0枚なら何もしない。
- クリップを単独で配置し、1枚目のアンカーへ留める操作も用意する。
- 未所属カードをクリップへ近づけて離すと束の最後へ追加。受け付ける位置を表示する。
- クリップまたは束のどの紙でも、通常ドラッグでは束全体を平行移動。一度だけ移動し、選択重複で二重に動かさない。
- Alt＋紙ドラッグ：その1枚だけ抜いて移動。残りは順番を保って間を詰める。
- 1枚目を抜いたら、次の紙は現在位置のまま新しい基準になる。クリップと残りを再配置。1枚になってもクリップを残す。最後の1枚を抜くと空のクリップは消す。
- Ctrl/⌘＋Shift＋G：選択に含まれる束をすべて解除（クリップ削除）。無関係なものは無視。
- クリップ削除：紙は消さず、現在位置で解放。紙のどれかを削除した場合もクリップを削除し、選ばれた紙以外はその位置で解放。束ごとの一括削除は今回保留。
- ロックは束単位。紙またはクリップへのON/OFFを束全体へ一括適用し、以前の個別状態は記憶しない。人間はロック中の束を移動・サイズ変更・追加・抜き取り・解除・削除できない。文章・色等の編集は維持する。AIの編集権限は従来どおり。旧データに混在があれば、1個でもONなら束全体をONへそろえる。
- 保存・読込・Undo・Redo・コピーでも関係を維持する。クリップ自体のコピー／カットでは束全体を対象にする。紙だけをコピーした場合は独立したカードになる。部分コピーでは外部の束へ接続しない。

## 見た目と編集

意匠はゼムクリップとダブルクリップの2種類。まず黒いダブルクリップを標準にする。本体は色変更可能で、持ち手は銀色。サイズは一つの数値で縦横比を保持し、小・中・大の候補と数値入力。寸法の基準を本文の文字サイズには依存させない。

初期値は仮にサイズ64、オフセット32。実物を見て調整する。クリック判定には余裕を持たせる。クリップの絵は束の最前面で描画する。

## AIからの操作

専用の変更ツールは増やさず、`desk_execute`を使用する。`type: "clip"`に以下を指定する。

| キー | 内容 |
| --- | --- |
| `clipMembers` | 順序付きのカードID配列。空なら単独クリップ |
| `clipAnchor` | `top-left`等の8点名 |
| `clipOffset` | 0以上の間隔（初期32） |
| `clipSize` | 横幅に相当するサイズ（初期64） |
| `clipStyle` | `binder`または`wire` |
| `fill` | 本体色 |

位置・幅・高さは所属とサイズから導出する。束のカードまたはクリップの位置を変更すれば束全体が移動する。紙を抜く場合は`clipMembers`からそのIDを除外し、必要なら同じバッチで紙の位置を変更する。クリップの削除で解放できる。メンバーの重複や二重所属は拒否する。

この試作は保存形式を拡張するため、旧MCPを起動したまま新しいブラウザUIだけへ切り替えない。現在の机を保存してからMCPを再起動し、新しいUIと合わせて使用する。

## SVG意匠と向き

おっさん提供のSVG原本を`src/assets/clips/`へ配置。ゼムは48×64、ダブルクリップは64×48。`clipSize`は回転前の長辺を表し、縦横比を保持する。上中央を0°として、右上45°、右90°…左上315°。SVG中央を留め位置と回転の中心にし、回転後の外接矩形を選択・クリック範囲に使う。色は本体のみ変更し、銀色の持ち手を保持する。SVGのクラス名はアプリと衝突しない名前へ変換して描画する。

ゼムは回転方向に沿って、長辺の25％だけ紙の内側へ押し込む。回転後の外接矩形も同じ分だけ移動し、選択枠とクリック範囲を絵柄に合わせる。ダブルクリップの位置は変えない。

ツールバーのクリップボタンは「テキスト」の直後に配置し、既存と同じTablerのpaperclipアイコン・小さなキャプション・高さを使用する。

## 自動サイズ（2026-10-22）

クリップのプロパティ「サイズ指定」で、数値指定／自動（1枚目に合わせる）を選ぶ。新規作成（ボタン・Ctrl+G・MCP追加）は自動サイズを既定にする。既存クリップの設定は変更せず、古い保存データでclipAutoSizeが省略されている場合は数値指定を維持する。

`clipAutoSize:true`のとき、1枚目の表示上の矩形の短辺×0.15を実サイズとし、48〜384に制限する。縦長の文章が長くなっても、短辺が変わらなければ拡大しない。1枚目のリサイズ・型抜き・入れ替えにも追従する。留め位置8方向とゼム／ダブルクリップの回転・差し込み量は実サイズに合わせる。

`clipSize`は元の数値指定を保持し、自動計算値で上書きしない。自動中は数値欄を無効にして保持値を表示する。数値指定へ戻すと保存していたサイズに復帰。空のクリップは自動指定でも`clipSize`を使う。最後の紙を外すとクリップが消える従来仕様は変更しないため、この場合の縮小アニメーションは追加しない。

`clipAutoSize`省略／falseは従来の数値指定。クリップ専用属性として検証・公開・保存・Undo・机内コピーに対応する。width/heightは実サイズから従来どおり導出する。自動サイズの別の保存キーは増やさない。ロックした束の人間によるサイズモード変更は拒否する。

MCPのモデルとツール説明にも追加しているため、実机へ反映するにはMCP再起動が必要。

## 選択中の所属補助線（2026-10-22）

人間がクリップに所属する紙を選択すると、その紙から所属クリップの中心まで補助線を1本表示する。複数選択は対象ごとに表示。クリップ自体や未所属の紙、AI指差しだけでは表示しない。選択解除で消える。

始点は紙の表示矩形の四隅＋各辺中央の8点のうち、クリップ中心との二乗距離が最小の点。角丸の内側へ寄せず、矩形の角を用いる。追従接続が無効な2枚目以降にも表示可能。型抜きONでは表示窓の矩形を使う。

選択枠と同じ色・太さ、不透明度60%、画面上1.5px固定、4px線・4px空きの破線。矢印・端点記号なし。選択枠・ハンドルより先に描画し、pointer-events:noneで操作対象にしない。

所属や位置・寸法・自動サイズの変更、ズーム、ドラッグプレビューへ追従する。選択オーバーレイ内だけの表示で、机データ・Undo・保存形式・オブジェクト一覧には含めない。既存PDF出力もオーバーレイを除去するため対象外。

## 間隔の割合指定（2026-10-22）

間隔の指定を「固定距離」「割合（直前の紙）」から選べる。固定距離は従来どおりで、既存ファイルも固定距離として読む。

割合では、N+1枚目の対応アンカーをN枚目の対応アンカーから内側へずらす。

- 左右の留め位置：N枚目の幅 × 割合
- 上下の留め位置：N枚目の高さ × 割合
- 四隅：N枚目の幅・高さにそれぞれ割合を掛けてずらす

100%なら同寸法の紙は辺または角で接する。異なる寸法では対応アンカー基準のため、重なり具合は変わる。サイズ変更やメンバー変更時も後続を再計算する。

割合の候補は10・30・60・90・100%。直接入力は有限の0%以上で、100%超も可。初めて割合へ切り替えた際は30%。0%は対応アンカーが重なる。固定距離へ戻すと以前の固定値を使う。

保存・MCP属性：`clipOffsetMode: "fixed" | "percent" | "base-short-side"`、`clipOffsetPercent: number`。方式省略はfixed、割合省略時の実効値は30。`clipOffset`は固定用として保持し、割合との相互換算はしない。複製・Undo・保存読込で値を保持する。新しい属性を含むファイルは対応版で開く。


### 1枚目の短辺を基準にする割合

「割合（1枚目の短辺）」を追加。`clipOffsetMode: "base-short-side"` として保存する。1枚目の `min(width,height) × clipOffsetPercent / 100` を各段共通の距離にし、固定距離と同じ留め位置から中心への方向へ累積配置する。四隅でもこの距離は斜め移動の長さであり、幅・高さへ別々には掛けない。後続の紙の寸法には依存しない。1枚目のサイズ変更・差し替えで再配置する。

2種類の割合指定は同じclipOffsetPercentを共有し、候補・初回30%・0%以上という条件も共通。固定距離のclipOffsetは別途保持する。
