# UIのライト／ダーク切替

2026-10-19。ヘッダーの「ひとりで考える」と保存の間に36pxのアイコンボタンを配置。ライト時は月（ダークモードに切替）、ダーク時は太陽（ライトモードに切替）。Tabler SVG、線幅1、ツールチップとアクセシブル名付き。

明示操作で切り替え、localStorageのtabletop-ui-themeへ記憶する。初期はライト。OSへの自動追従は行わない。保存領域が使えなくてもその場の切替は動く。

ルートのdata-themeを変え、CSS変数とUIに限定した上書きでパネル・ボタン・入力欄・数値／線種／色／リアクションのパレット・インライン編集欄を切り替える。机の壁紙、パーツ、文字、枠色、選択、履歴、revisionは変えない。机ファイルの保存・読込でもUIテーマは変わらない。

暗い机が欲しい場合は、壁紙charcoalを別途選ぶ。ライトUI＋暗い机、ダークUI＋明るい机も可能。枠色は壁紙と机側の設定に従い、UIテーマは参加者のブラウザ側の好みとして扱う。

実装：src/ui-theme.ts、src/ui-theme.css。表示切り替えはブラウザ内で実行し、MCPからも取得・設定できる。ポーリングはない。

## AIからの確認と切り替え

- `desk_context` の `ui.theme` または `desk_ui_get` で、接続中ブラウザの現在値（`light` / `dark`）を取得する。
- 人間から依頼された場合、`desk_ui_set({theme: "light" | "dark"})` で明示的に切り替える。ボタン・localStorageも同じ経路で更新する。
- UI状態は机のリビジョンとは独立して変わる。画面の案内には必要に応じて再取得する。共有GETの机データには含めない。
- 「ひとりで考える」中は取得のみ許可。変更は拒否する。机ファイル・Undo・カメラ・選択には影響しない。
