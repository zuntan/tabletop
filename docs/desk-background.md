# 机の壁紙（設定画面は未実装）

2026-10-18に内蔵の3種類を追加。2026-10-19に暗い無地と壁紙別の枠色を追加。壁紙の設定画面・画像の持ち込みは未実装。UIテーマは[独立した切替](./ui-theme.md)。

## 試用の柄

| `wallpaper` | 見た目 |
| --- | --- |
| `none` | 従来の無地とドット。初期状態 |
| `wood` | 薄い木目と板の継ぎ目 |
| `cutting-mat` | 緑のカッターマット。細線・太線・中央目印 |
| `pink-notebook` | 淡いピンクのノート。罫線と余白線 |
| `charcoal` | 暗いチャコールの無地。既定ではドットなし |

柄は内蔵SVGパターン。外部画像やフォントの取得は行わない。机上の座標に固定し、パン・ズームで机と一緒に動く。壁紙は文書のパーツではなく、選択・当たり判定・一覧・全体表示の範囲に含めない。

## AIから切り替える

既存の `desk_execute` へ `background_update` を追加。

```json
{
  "operations": [
    { "kind": "background_update", "patch": { "wallpaper": "wood" } }
  ]
}
```

`cutting-mat`、`pink-notebook` も同じ操作。無地へ戻すには `none`。

暗い机は `charcoal`。UIのダークモードを切り替えても壁紙は変わらない。

## 壁紙に合う枠色

| 壁紙 | 人間の選択 | AIの指差し |
| --- | --- | --- |
| none | #2563eb（青） | #15803d（緑） |
| wood | #1d4ed8（青） | #7c3aed（紫） |
| cutting-mat | #facc15（黄） | #e879f9（ピンク） |
| pink-notebook | #1d4ed8（青） | #047857（緑） |
| charcoal | #60a5fa（明るい青） | #a3e635（黄緑） |

`settings.background.selectionColor` / `pointingColor` はそれぞれの上書き色。nullは壁紙の既定色を使う指定で、机ファイルへ保存する。壁紙を指定したbackground_updateでは、上書き色を既定へ戻す。同時に上書き色を明示すればその値を優先。壁紙を指定せず色だけ更新する操作も可能。Undo・読込で机と一緒に復元する。

選択枠・リサイズハンドル・ロック中の枠とバッジ・囲み選択・接続端点の通常色に適用。Binding済み端点の緑は接続状態を示すため保持。AIの点線枠にも適用する。人間とAIの区別は色に加えて枠の位置・線種・ハンドルの有無でも維持する。

`desk_settings`／`desk_context` の `settings.background` で取得できる。

```json
{
  "wallpaper": "none",
  "color": null,
  "showGrid": null
}
```

- `color: null` は柄の既定色。色の指定で背景色を上書きできる。nullへ戻すと、その柄の色へ戻る。
- `showGrid: null` は自動。無地では従来のドットを表示し、柄付きでは重複を避けて非表示。true／falseで明示的に上書きできる。
- 部分更新。省略項目は維持する。色やグリッド表示を以前に上書きしていた場合、柄の既定へ戻すにはそれぞれnullを指定する。
- ドットの表示はグリッド吸着のON/OFFとは別。壁紙変更でスナップの設定・座標を変えない。
- 変更は共有revision・履歴・Undoの対象。1つの操作として戻せる。
- 机の外観を変えるため、人間の意図がある場合に操作する。

パーツの位置・寸法・色・文章・採番・選択、UIの配色、カメラの位置は変更しない。半透明のパーツから背景が透ける見え方は変わる。

## 保存と互換性

机の設定として保存・読込する。柄は識別子だけなので画像アセットを増やさない。保存形式versionは1のまま。

backgroundを持たない古いファイルは、従来どおりの無地・ドットに補完する。一方、backgroundを含む新しいファイルは、古いアプリの厳密なSchemaでは拒否されるため、UIとMCPを揃えて更新する。

新サーバーから古いUIへ背景の変更を要求した場合は、保存・UI更新を案内して編集前に拒否する。
