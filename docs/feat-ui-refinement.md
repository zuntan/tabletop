# UI Refinement ブランチの作業記録

対象ブランチ: `feat/ui-refinement`

このブランチでは、サイドバーの操作性、インライン編集、ピン体系の表示、オブジェクトリストとフィルターを改善しました。作業机上のパーツ内容や接続方法の変更は対象外です。

## 主な変更

### インライン編集

- インライン編集欄の寸法を対象オブジェクトの枠に合わせました。
- オブジェクトのリサイズに合わせて編集欄の外枠も追従します。

### サイドバーとプロパティ

- サイドバー各タブの下部に72pxの余白を設け、末尾の項目を操作しやすくしました。
- サイドバーの操作ボタンの文字サイズをツールバーのキャプションに合わせました。
- 選択中パーツのロック操作をプロパティ欄の先頭に配置しました。スイッチでロック状態を切り替え、ロック状態が混在する選択では一括でONにできます。
- ピン体系は、選択中の全パーツがピンの場合に限り表示します。ピン配置ボタンはピン体系から除き、上部ツールバーの配置ボタンは維持しています。

### オブジェクトリスト

- タブ内の見出しを「オブジェクトリスト」にしました。
- 選択が変わり、オブジェクトタブが表示されている場合は、最上段の選択パーツがリストの可視範囲に入るようスクロールします。タブが非表示の間は処理を保留し、タブを開いたときに行います。同じ選択の再描画では再スクロールせず、選択がない場合もスクロールしません。
- リスト項目をクリックすると選択し、「選択範囲」ボタンと同じカメラ処理で選択範囲を画面内に表示します。Shiftクリックで複数選択した場合も、その選択範囲を表示します。

### オブジェクトフィルター

- オブジェクトタブにのみ表示する「フィルター」領域を、タブ見出しとスクロール領域の間に配置しました。他のタブでは領域を表示しません。
- 「適用」スイッチがOFFの間は、カテゴリボタンの状態にかかわらず全パーツを表示します。カテゴリボタンを操作しても一覧や選択可視化スクロールには影響しません。
- 「適用」がONの間は、ONになっているカテゴリのパーツだけを表示します。
- カテゴリと対象パーツの対応は次のとおりです。
  - ピン: ピンパーツ
  - テキスト: テキストパーツ
  - 図形: 矩形、角丸矩形、楕円
  - 線: 線、矢印
  - 画像: 画像、SVG
  - その他: Web資料、リンク
- 初期状態は「適用」OFF、ピンのみON、その他のカテゴリはOFFです。
- 「All ON」「All OFF」でカテゴリ状態を一括変更できます。「適用」の状態は変わりません。
- 「適用」のON/OFF切替時は新しい表示対象に応じて選択パーツの可視化処理を行います。適用ON中のカテゴリ切替や一括変更でも同様に処理します。選択中のパーツが表示対象に含まれない場合はスクロールしません。
- 件数表示はフィルター適用後の表示件数です。
