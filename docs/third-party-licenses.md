# 第三者ライセンスと配布通知

## 対象と使い方

Tabletop自身はルートの [LICENSE](../LICENSE) にあるMITです。第三者部分は各ライセンスを維持します。

- [全通知・ライセンス全文](../public/licenses/THIRD_PARTY_NOTICES.txt)
- [監査時の直接・間接依存338件（開発用を含むCSV）](./licenses/dependency-audit-2026-10-24.csv)
- [名称・版・出典・個別通知への対応表](../public/licenses/generated/manifest.json)
- [内部コードの補足原本](../licenses/supplemental/)

通知集はpackage-lock.jsonの本番依存全体を対象にします。現在は263配置・260種類/版。ブラウザに含まれるものだけでなく、MCPサーバーの依存や、保守的に推移依存の型・CLI等も含めます。開発用依存、Node本体、Chrome本体の配布をカバーするものではありません。

Aboutには主要な直接利用ライブラリとTabler Iconsだけを並べ、Tabler・Mermaid・markdown-it・Pickrを先にします。間接依存と補足通知は「すべてのライブラリ・ライセンス」から読めます。通知集の網羅範囲は減らしません。

Aboutの「ライブラリライセンス」は枠なしで約4行（72px）のスクロール一覧です。クレジット以降を中央寄せにし、行間・余白を詰め、通常の画面ではAbout全体のスクロールを避けます。小さな画面では全体スクロールも残します。各リンクから著作権表示と全文を別タブで開けます。全通知をまとめたリンクも置きます。

## 再生成と梱包

`npm ci` の後、`npm run licenses` でローカルの依存原文から再生成します。ネット接続は不要です。`npm run build` でも先に実行し、Viteが `public/licenses/` を `dist/licenses/` にコピーします。本体MITのコピーも含みます。生成済みの通知はソース配布でも利用できるよう追跡します。

- バージョン違い、未確認ライセンス、ライセンスファイル欠落は生成エラーとし、無通知でのビルドを避けます。
- DOMPurifyはApache-2.0の選択肢を採用。上流の代替ライセンス本文も参照用として保持します。
- Khroma 2.1.0はpackage.jsonの宣言がありませんが、同梱 `license` のMIT本文を根拠にします。別版へ更新時は再確認します。
- 同一版が複数配置される場合は通知原文が同一か確認してまとめます。
- 各パッケージのLICENSEだけでなくNOTICE、内包コード用のライセンスファイルも収録します。
- 新しい依存や版を導入した場合は、代表ライセンス以外のファイル別例外も再点検します。

最終ZIPでは `dist/licenses/` を除去せず、本体LICENSE・この案内も保持してください。サーバーのnode_modulesを配布する場合も同梱の表示を削除しません。開発用node_modulesやブラウザ・Node実行環境を丸ごと同梱する場合には別途その複合通知が必要です。別OS向け開発用optional50件は当初監査で宣言のみ確認したもので、今回の本番通知集の対象外です。

## ファイル別の補足

### ELK / elkjs

elkjs 0.9.3はEPL-2.0です。上流の著作権ヘッダー、EPL本文と対応ソース入手案内を保持します。公式リリースはELK 0.9.1を基底とし、ELK PR955の修正も含むと明記しています。基底版と追加修正の固定参照を `elk-sources.txt` に記録しました。Tabletopは上流コードを編集せず、Viteによる機械的な束ね・圧縮を行います。ソースの対応は上流のリリース記載を根拠とし、独自の再ビルド一致検証を行ったという意味ではありません。

上流ビルドのGWT・Guava・EMFと、内包web-worker shimについても、Apache/EPLの本文・上流COPYING・元ヘッダーを補足収録します。GWT SDK全体の配布を意味しません。原本の取得先は `licenses/supplemental/sources.json` を参照してください。

公式リリース：https://github.com/kieler/elkjs/releases/tag/0.9.3

### KaTeX

MITコードに加え、`src/stretchy.ts` が明記するOFL-1.1由来SVG字形の著作権表示と全文、`src/utils.ts` のFacebook React由来Apache-2.0の説明と全文を保持します。KaTeXフォントバイナリは配布していません。

### es-toolkit / lodash-es / Tabler

es-toolkitのNOTICEにあるLodash/Underscore由来の表示を収録。lodash-esの複数著作権者を元のまま保持します。Tabler Iconsは既存MIT本文を保持します。Aboutの見出しだけでこれらの本文を代替しません。

## 素材についての採用判断（2026-10-24）

ずんたんが、開発用の机データに問題となる画像を入れていないこと、およびセンパイ・おっさん制作の小物・クリップ・壁紙等を採用継続する方針を確認しました。調査側でも具体的な問題画像は見つかっていません。出典記録の薄さを理由に一律削除や差替えを求めません。この記録は、あらゆる第三者権利を独立に証明したという意味ではなく、制作経緯と利用者確認に基づく採用判断です。

ミッキー形はずんたんの判断で選択肢・SVGとも削除しました。旧データのIDは丸シールへ置換して読み込みます。元の選択位置にはTablerのFilled `confetti`（クラッカー）を追加しました。旧 `mickey` の変換先は引き続き丸です。

## 確認

通知網羅性テストはlockfileと通知manifestの版・欠落・本文、ELK/KaTeX等の補足を確認します。AboutのE2Eで枠なしスクロール、個別全文の取得、主要著作権表示を確認します。配布形式が確定したら、最終アーカイブをもう一度確認してください。
