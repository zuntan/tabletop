# BHアニメ削除（たたき台）

2026-10-21。ツールバーの「削除」は押すたびに落下／吸引をランダム選択し、その一回の選択全体で同じ演出を使う。

選択した部品を、プロパティ下部の「削除」ボタンで演出付き削除。
横の ▾ メニューから「落下で削除」「吸引で削除」を選んでも実行できる。
通常ボタンは最後に選んだ方式（初期値：落下）を使う。方式は保存データに含めない。
Delete／Backspaceは従来の即削除。MCPのdeleteも従来どおり。

## データと表示

- 対象の描画ノードをブラウザ側でPNGへ取り出す。添付・接続関係は通常削除のルールを使う。
- 選択全体を一回の通常deleteバッチで確定してから、画像だけを一枚ずつ表示・変形する。
- まだ順番の来ない残像は元位置に表示する。穴は各対象の下／右下へ出る。
- Undoは選択全体を一回で復元。演出中でも通常のUndoでよい。
- Undo・別の編集・ロードによるrevision/session変更、カメラ移動、表示領域変更、
  切断、非表示化、動きを減らす設定への変更で残像を破棄する。データの再実行はしない。
- キャプチャ準備中に状態が変わったり、キャプチャが失敗した場合は削除を確定しない。
- クリップだけを消すと紙は残る。紙の削除でクリップも消える場合はクリップの残像も含む。
  生き残る紙や接続線を勝手に削除しない。ロックに関しても既存deleteの規則に従う。

## 描画の範囲と制限

テキスト・図形・線・ピン・画像・SVG・Mermaid・小物・クリップを描画ノードから取得。
Web資料のiframe本体は取得せず、カード内へ明示的な代替文を入れる。
外部画像はCORS対応時だけ自己完結画像へ変換可能。失敗時は通常Deleteで削除できる旨を表示する。
読み込み中のMermaidは表示完了まで待ってもらう。見た目の完全一致は要求しない。
PNGの縮小は部品寸法・現在ズーム・対象数に応じて行い、単体約200万画素・全体約800万画素を目安にする。
アニメはCanvas 2D。残像のレイヤーは操作を遮らない。画面外にある対象や穴は画面外のまま。
動きを減らす設定／非表示タブでは即削除する。

## 方式

- 落下：横線から楕円の穴へ。対象を下へ移動し、入口でマスク。手前の縁を最後に描く。
- 吸引：同じラスタを粗い網目に貼り、頂点の位置別に回転・収縮。穴へねじり込む。
- 共通の前振り300ms、飲み込み850ms、閉じる300ms。合計1500ms／枚。

比較用の「メニュー → BH比較（実験）」も残す。こちらは削除しない再生専用。
タイミング、穴の配置、順序や多数選択のテンポは実際の操作を見て調整する。
