## v0.1.2

Windowsでビルドした後、生成されたライセンスファイルの変更によりGitでの更新が止まる問題を修正しました。

- ライセンス生成の入力・出力と、lockファイルの検証用ハッシュに使う改行をLFへ統一しました。
- Gitの改行ルールを明示し、Windowsの改行設定による不要な生成差分を抑えました。
- アプリの機能・机ファイル形式は変更していません。

### 旧版から更新する際の注意

旧版のビルドですでに発生した差分は、新版を取得する前に戻す必要があります。`public/licenses` の変更でpullが止まる場合、自分で編集した内容がないことを確認してから実行してください。

```sh
git restore -- public/licenses
git pull --ff-only origin main
npm ci
npm run build
```

`git restore` は同ディレクトリの未コミットの変更を破棄します。対象外の変更は個別に確認してください。更新前に机を保存し、対象MCPを停止してください。更新後はMCPを再起動し、ブラウザも読み込み直してください。タグ指定で更新する場合は[INSTALL](../INSTALL.md)を参照してください。

## v0.1.1

日本語・英語の切り替えに対応しました。英語の説明文書とチュートリアル机も追加しています。

### 英語対応

- メニュー、プロパティ、ダイアログ、通知、エラーなどを日本語・英語で表示できます。「メニュー → 言語」から切り替えられます。
- 初回はブラウザの言語を使い、日本語以外では英語で始まります。選んだ言語はブラウザに記憶します。
- 英語版のREADME・INSTALL・利用ガイドと、別ファイルの英語チュートリアル机を追加しました。
- AI向けの説明・ヘルプを英語に整理しました。日本語での会話にも引き続き使えます。
- 英語の看板小物「VACANT LOT」「WORK IN PROGRESS」「TEMP AREA」を追加しました。日本語版の小物も残しています。

### ハンコの改善

- 固定の印影文字をSVGの輪郭にし、環境のフォントによる字形の違いや欠字を抑えました。日本語の意匠はそのままです。
- GOOD・BAD・CAUTION・DANGER・Excellentを追加し、38種類をメニューに並べました。
- 日付の位置・太さ・余白、区切り線を調整しました。Excellentは傾けた場合も、日付を含めてカード内に収めます。
- 「日付付き」を大きい見本の下へ移動しました。大きい見本のクリックでも押せます。日付の有無で印影のデザインは変わりません。

### 操作の改善

- カードのプロパティに「枠を文字にあわせる」を追加しました。横幅と文字サイズを保ち、本文と余白に合わせて高さを調整します。スナップONでは間隔に合わせて切り上げます。
- シールの初期選択を、1列目は赤丸、2列目は緑の星にしました。貼り付け済みのシールは変わりません。
- 言語切り替え時の候補メニュー見出しや、画像出力時のWeb資料の代替表示を調整しました。
- READMEの図版を、暗い背景でも読みやすくしました。

### 既存の机と更新

表示言語を変えても、保存済みの本文・名前・印影は翻訳されません。机ファイルの保存形式は維持し、既存の机を引き続き使えます。ハンコは同じIDのまま、今回の意匠で描画されます。

更新前に机を保存し、Tabletop本体とブラウザ画面の両方を更新してください。自動保存はありません。導入・更新は[ドキュメントの案内](README.md)から確認できます。
