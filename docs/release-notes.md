## v0.2.0

カードの文章を扱う操作を充実させ、テキストからUIの画面ラフを描けるWireloomカードを追加しました。

### Wireloomと図の編集

- 「Wireloom」から専用カードを作成し、記法のソースを編集して画面ラフをSVGで表示できます。日本語・英語、差し色付きのボタンなどに対応します。
- Wireloom 0.7.0を固定して使用し、Tabletop側で日本語などの文字幅を補正しました。本文に `text "注意書き" width=240` と幅を指定すると折り返します。この幅指定はTabletop側の拡張です。
- Mermaid・Wireloomの編集欄に、押している間だけ未確定の図を確認できる目のボタンを追加しました。離すとソースへ戻り、プレビューだけでは机を変更しません。
- 両方のソース編集欄は、カードの表示高さを基準に160〜480pxで開き、画面に収まるよう調整します。
- Mermaidのボタンを、図のつながりを表すアイコンへ変更しました。

### Markdownと文字の操作

- Markdownの表、タスクリスト、HTTP(S) URLの自動リンクに対応しました。チェックボックスはクリックで切り替えられ、保存・Undoにも対応します。
- カード本文を長押しすると、その場で文字を選んでコピーできます。Ctrl／⌘＋Aでカードの全文を選び、Escやカード外のクリックで終了します。選択中のDelete／Backspaceではカードを削除しません。
- リンク全体・画像・チェックボックスをコピーすると、URLや参照先、チェック状態をMarkdownの記法で残せます。リンクの一部分は文字だけをコピーします。
- AIからも、1枚のカードの全文や文字位置の範囲を選択できます。人間がコピーするための一時的な選択で、本文や保存データは変わりません。
- 文字選択モードのカード枠を一点鎖線にして、通常の選択と見分けやすくしました。

### 画像参照と書体

- Markdownに外部画像のURLと、同じ机の画像・SVG・Mermaid・Wireloom・QRなどの参照を置けます。同じ机の参照は `![説明](tabletop://./カードID)` と記述します。
- 外部画像はURLのまま保存します。配信元の制限やオフライン状態により表示・PNG/PDF出力できない場合は、代替表示になります。
- 「机の見た目」でカード本文の書体を机ごとに選べます。ゴシック・明朝・等幅それぞれに優先フォント名を指定でき、コードとMarkdownの編集欄は等幅の指定を使います。
- 書体設定は机に保存され、Undo／Redoに対応します。新しい机には、最後に使った書体の設定を引き継ぎます。

### 配置の操作

- 「一つ前へ」「一つ後ろへ」を追加しました。重なる相手を基準に一段ずつ重なり順を変え、選んだもの同士の順番は保ちます。
- クリップ内の紙は、離れた配置でも束の中の順番を変更できます。クリップと紙を同時に選んだ場合や、定規・クリアファイルのまとまりも扱います。
- 大きく表示されているカードなどには、四隅と各辺中央の8点のリサイズハンドルを表示します。小さく表示されている場合は右下の1点になります。角は縦横、辺の中央は一方向だけを調整します。

### 修正と更新時の注意

- MCP接続時にTabletopが名乗るアプリ版番号を、Aboutと同じ `package.json` から読むようにしました。
- MCP関連の間接依存であるHono系を修正版へ更新し、依存関係の監査で検出された指摘を解消しました。
- 既存の机は引き続き読み込めます。保存形式の番号は維持していますが、Wireloomなどの新しい要素や設定を含む机は、旧版では開けない場合があります。
- 日本語の幅や折り返しは近似計算です。書体の変更により改行や必要な高さが変わる場合は、カードの枠を調整してください。図内の書体とMarkdown本文の書体設定は独立しています。
- 更新前にすべての机を保存し、対象のMCPを停止してください。新版を取得して `npm ci` と `npm run build` を実行し、MCPを再起動してブラウザ画面も更新してください。自動保存はありません。

## v0.1.2

Windowsでビルドした後、生成されたライセンスファイルの変更によりGitでの更新が止まる問題を修正しました。

- ライセンス生成の入力・出力と、lockファイルの検証用ハッシュに使う改行をLFへ統一しました。
- Gitの改行ルールを明示し、Windowsの改行設定による不要な生成差分を抑えました。
- アプリの機能・机ファイル形式は変更していません。

### 旧版から更新する際の注意

旧版のビルドですでに発生した差分は、新版を取得する前に戻す必要があります。`public/licenses` の変更でpullが止まる場合、自分で編集した内容がないことを確認してから実行してください。

```sh
git restore -- public/licenses
git pull --ff-only origin main
npm ci
npm run build
```

`git restore` は同ディレクトリの未コミットの変更を破棄します。対象外の変更は個別に確認してください。更新前に机を保存し、対象MCPを停止してください。更新後はMCPを再起動し、ブラウザも読み込み直してください。タグ指定で更新する場合は[INSTALL](../INSTALL.md)を参照してください。

## v0.1.1

日本語・英語の切り替えに対応しました。英語の説明文書とチュートリアル机も追加しています。

### 英語対応

- メニュー、プロパティ、ダイアログ、通知、エラーなどを日本語・英語で表示できます。「メニュー → 言語」から切り替えられます。
- 初回はブラウザの言語を使い、日本語以外では英語で始まります。選んだ言語はブラウザに記憶します。
- 英語版のREADME・INSTALL・利用ガイドと、別ファイルの英語チュートリアル机を追加しました。
- AI向けの説明・ヘルプを英語に整理しました。日本語での会話にも引き続き使えます。
- 英語の看板小物「VACANT LOT」「WORK IN PROGRESS」「TEMP AREA」を追加しました。日本語版の小物も残しています。

### ハンコの改善

- 固定の印影文字をSVGの輪郭にし、環境のフォントによる字形の違いや欠字を抑えました。日本語の意匠はそのままです。
- GOOD・BAD・CAUTION・DANGER・Excellentを追加し、38種類をメニューに並べました。
- 日付の位置・太さ・余白、区切り線を調整しました。Excellentは傾けた場合も、日付を含めてカード内に収めます。
- 「日付付き」を大きい見本の下へ移動しました。大きい見本のクリックでも押せます。日付の有無で印影のデザインは変わりません。

### 操作の改善

- カードのプロパティに「枠を文字にあわせる」を追加しました。横幅と文字サイズを保ち、本文と余白に合わせて高さを調整します。スナップONでは間隔に合わせて切り上げます。
- シールの初期選択を、1列目は赤丸、2列目は緑の星にしました。貼り付け済みのシールは変わりません。
- 言語切り替え時の候補メニュー見出しや、画像出力時のWeb資料の代替表示を調整しました。
- READMEの図版を、暗い背景でも読みやすくしました。

### 既存の机と更新

表示言語を変えても、保存済みの本文・名前・印影は翻訳されません。机ファイルの保存形式は維持し、既存の机を引き続き使えます。ハンコは同じIDのまま、今回の意匠で描画されます。

更新前に机を保存し、Tabletop本体とブラウザ画面の両方を更新してください。自動保存はありません。導入・更新は[ドキュメントの案内](README.md)から確認できます。
