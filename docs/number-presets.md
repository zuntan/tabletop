# 数値入力の候補

2026-10-19。微妙な差の候補を増やさず、よく使う値をマウスで選べる小さな「候補」ボタンを数値欄の横に追加。色選択UIに合わせた白い角丸パレットに数値を並べ、現在の候補を強調する。文字色は周囲のUIに合わせた灰色。ピン設定の既存selectも文字色を揃える。直接入力は残し、保存形式・許容値・既定値は変更しない。

パレットは選択、外側クリック、Escapeで閉じる。選択とEscapeでは元のボタンへフォーカスを戻す。スクロールやリサイズ時にも閉じ、画面外にはみ出さない位置へ表示する。

| 項目 | 候補の表示順 |
| --- | --- |
| 線幅 | 1・2・4・8・16 |
| 文字サイズ | 12・16・24・32・48 |
| 塗り透過率（%） | 100・90・70・50・30 |
| 角丸 | 0・4・8・16・24 |
| 内側余白 | 0・8・16・24・32 |

透過率は100が透明。0も直接入力できる。角丸0は角丸なし。候補外の1.5や余白30などもそのまま保持する。

作成時の線幅・塗り透過、個別プロパティの5項目、ピンシリーズの該当項目、糸の線幅・透過に適用。新しい設定項目や数値の制限は追加しない。

確定の方法は既存どおり。上部の作成設定とピンシリーズは候補選択で即時反映し、プロパティは候補から入力した後「変更を適用」でまとめて反映する。無効な数値欄の候補も無効にする。

ピン設定の2列配置は、名前／表示、書式／形、幅／高さ、文字サイズ／枠を文字にあわせる、線幅／塗り透過の順。関係する項目を同じ段に揃える。
