# Tabletop guide

[日本語](../README.md) · [Tabletop](../../README_en.md) · [Installation](../../INSTALL_en.md)

Tabletop is a place for humans and AI to spread out material, look at it, move it and think together. Read the parts you need; this is not a course you must finish in order.

These English guides describe the v0.1.1 development work. The published v0.1.0 release predates English UI support; the English tutorial file is included in this branch for the next Pages deployment.

## Try it first

[English tutorial desk file](../tabletop/tabletop-guide-en.tabletop) · [Japanese public tour](https://zuntan.github.io/tabletop/?desk=desks/tabletop-guide.tabletop)

Download the English file and use File → Upload in the v0.1.1 browser or normal edition. No AI connection is needed to explore it. Select the green wayfinder near the central introduction and press ▶ to visit explanations and examples. See [Touring the tutorial](tutorial.md) for navigation and the PDF overview.

## Normal edition and static Pages

To work **with AI**, connect the normal edition to a supported AI environment through MCP. Operate the desk in your browser and continue talking in the AI chat.

To let someone **try or view a desk without AI**, use static Pages. It also supports basic human editing and downloading the result.

Both use `.tabletop` files. Editing a publicly served desk does not change the original on the website.

## Keep your work

**There is no autosave. Save before closing or reloading.** On static Pages, use File → Download. Save `.tabletop` as well as PDF/PNG if you want to keep editing later.

If you lose your place, clear the selection and use Fit all at the bottom right. Select a card and use Fit selection to read it. The Objects panel also helps find items.

The tutorial shows possibilities, not rules. Combine the tools in ways that suit your own desk.
