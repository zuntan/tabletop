# Pagesに置く机ファイル

公開したい `.tabletop` をこのディレクトリへ置きます。Pagesビルド時に `.tabletop` だけを `dist-pages/desks/` へコピーします。

`docs/tabletop/tabletop-guide.tabletop` は、公開後に `?desk=desks/tabletop-guide.tabletop` で開けます。別のプロダクトのPagesに置いた机は、そのURLを `desk` に指定できます。

公開対象は、774個のパーツを含む完成版チュートリアル `tabletop-guide.tabletop` です。同名のPDF版は [tabletop-guide.pdf](tabletop-guide.pdf) に保存しています。サンプル追加前の机は `docs_devel/desk-snapshots/circle-before-samples.tabletop` へ移し、公開対象から外しました。開発机の保存履歴は自動コピーしません。詳しくは [Pages版の案内](../pages.md) を参照してください。
