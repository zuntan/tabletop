# Tabletopのチュートリアル机

Tabletopの道具を、説明やサンプルを眺めながら試せる机です。カード、線、ピン、クリップ、ハンコなどを、一つの広い机に並べています。

[チュートリアル机を開く](https://zuntan.github.io/tabletop/?desk=desks/tabletop-guide.tabletop)

ブラウザからそのまま開けます。インストールやAIへの接続は不要です。

## はじめの一歩

開くと、中央の「Tabletop — 道具をたどる机」が表示されます。

近くの緑の道しるべを選び、現れる ▶ ボタンを押してみてください。「試しに、見やすい大きさへ」の案内へ進みます。そこで選択範囲の表示を試したら、次の道しるべから「01 カード」へ進めます。

以降も番号順にたどれますが、最初から最後まで順番に読む必要はありません。気になった道具へ寄り道してかまいません。

## 説明とサンプルを行き来する

内側の番号付きカードが、道具の入口です。外側には詳しい説明と、実際に置いたサンプルがあります。

- **緑の道しるべ**：紹介から詳しい説明へ進みます。
- **青い道しるべ**：紹介へ戻れます。
- **ピン①と②**：一つ選んで［◀ ▶］を押すと、説明とサンプルを行き来できます。

道しるべでの移動中は、拡大率を保って経路をたどります。途中で机をクリックすると、その場で止まれます。

## 自分で眺める

ホイールで拡大・縮小、Space＋ドラッグかマウスの中ボタンで表示位置を動かせます。

文字が小さいときは、読みたいカードを選び、右下の「選択範囲」を押してみてください。全体を眺め直すときは、選択を外して「全体」を使います。

机の位置関係をたどるのも、このチュートリアルの一部です。少し離れたサンプルや、余白の小物も眺めてみてください。

## 試した結果を持ち帰る

静的ページで編集しても、公開元のチュートリアルは変更されません。手を加えた机を残したいときは、「ファイル → ダウンロード」で保存できます。

手元では、保存した .tabletop をアップロードして続きを開けます。閲覧・保存・URL指定の詳しい説明は、[静的ページの案内](../pages.md)で扱います。

机全体を一枚で眺めたいときは、[PDF版](https://github.com/zuntan/tabletop/blob/main/docs/tabletop/tabletop-guide.pdf)もあります。PDFは一覧用の資料です。道しるべの移動や道具の操作を試すには、チュートリアル机を開いてください。

**ここにある並べ方や使い方は、一つの例です。自分の机では、好きな道具を好きな組み合わせで使ってみてください。**
