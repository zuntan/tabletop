# Pagesに置く机ファイル

公開したい `.tabletop` をこのディレクトリへ置きます。Pagesビルド時に `.tabletop` だけを `dist-pages/desks/` へコピーします。

例えば `docs/tabletop/guide.tabletop` は、公開後に `?desk=desks/guide.tabletop` で開けます。別のプロダクトのPagesに置いた机は、そのURLを `desk` に指定できます。

最初の公開対象は未指定です。開発机の保存履歴は自動コピーしません。詳しくは [Pages版の案内](../pages.md) を参照してください。
