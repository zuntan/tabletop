# シール：貼る、並ぶ、全部剥がす

2026-10-21。利用者提案の記録。未実装。実装順・詳細は別途相談。

## データと操作

親オブジェクトの属性として、色の順序付き配列・配置起点・共通直径・ズーム固定ON/OFFを保持する。独立オブジェクト・個別座標・アンカー・選択状態は持たない。親の移動・削除・複製に追従する。同色の重複を許し、追加順を保持する。

操作は色を選んで末尾へ「追加」と「全消し」のみ。個別削除・並べ替え・ドラッグは設けない。並びを変えたければ全部剥がして貼り直す。

## 配置

画面上の親の外接矩形の四隅を起点に、水平一列へ等間隔で並べる。

- 左上／左下：右へ伸ばす
- 右上／右下：左へ伸ばす
- 最初のシールを起点側に残し、後から内側へ伸ばす
- 右下で赤→青→黄を追加すると、画面左から黄・青・赤
- 起点はシール中心。輪郭から半分はみ出してよい
- 配置アンカー自体は描画しない
- 回転を将来導入しても画面上の外接矩形を基準とし、シール列は水平

直径は対象単位、全シール共通。ズーム固定ならピン同様に画面サイズ一定、OFFなら机の倍率に追従。まず単色の正円だけ。星などは将来案。

## 人間UI

プロパティには色選択・追加・全消し・配置起点・直径・ズーム固定だけ。現在の色・枚数は机上で確認する。一覧・縮小見本・個別編集を追加しない。

## 対象と役割

テキストに限定せず、図形・画像などへ共通適用。個別の図形輪郭は扱わない。自由配置には従来の図形を使う。リアクションは気持ち、ハンコは判断、シールは内容を邪魔しない分類・進捗・状態・評価の小さな印。

## 既存実装との相性・実装前に確認

既存リアクションの親属性・非操作のSVG表示・ズーム補正、ハンコの保存／複製追従を参考にできる。リアクションの重複禁止・固定列挙・トグル操作はシールへ流用しない。モデル検証、公開属性、保存／コピー／Undo、全描画経路、PDF／PNG／BHラスタ化にも対応が必要。
