## 3. 第三者ライセンスと素材

おっさんが調べた範囲では直接依存はMIT中心との報告。ただしセンパイによる独立確認も、間接依存までの監査も未完了。問題なしと断定しない。

公開準備時に確認するもの：

1. 実際のlockfileと配布物を対象に、直接・間接依存を列挙。
2. 各パッケージの実際のライセンス、著作権表示、必要なNOTICE等を確認。
3. 再配布に必要な文面を `THIRD_PARTY_NOTICES.md` 等に整理。開発用依存と配布に含むものも区別する。
4. 画像・SVG・アイコン・フォント等の素材をコードとは別に確認。外部から持ち込んだ資料を、当然にTabletopのMIT対象へ含めない。
5. Aboutには概要と詳細情報へのリンクを置く。独自の表示義務は加えない。

公式ライセンス文・各配布物の根拠を確認してから整備する。このメモは法的な確認や依存監査の完了を示すものではない。
