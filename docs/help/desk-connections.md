# 机を開くこととAIを接続すること

起動時に、接続する机か、人間だけが使う机かを明示して判断してください。初回起動かどうかで推測しません。

- `desk_browser_open({mode:"connected"})`（省略時もこちら）：新規／手動ペアリングの受付を開いてから起動。接続中の机がある場合は拒否。既存の机の復旧は保持した非公開ペアリング情報を使い、不要な新規受付を開きません。
- `desk_browser_open({mode:"standalone"})`：トークンやペアリング情報を渡さず、空の机を開く。受付を開く・接続を解放する操作は不要です。既存のAI接続があっても維持します。

AIが操作できる机は現在接続された1つだけです。接続なしで開いた別の机に対し、desk_summary／desk_execute等が作用するわけではありません。起動要求の成功は、OSへ要求したことだけを示します。閉じる操作は人間に任せます。

単独の机はアップロード／ダウンロードで使います。通常SAVE／LOAD・机リンクでのサーバー読込には、認証済みのMCP接続が必要。接続なしの机に自動接続したり、既存の接続を奪ったりしません。共同作業へ切り替える場合は、人間の指示に従い、両方の机の保存状況を確認して接続を引き渡します。

独自にブラウザで起動する場合も、サーバー自身の `/?connect=off`を開けば接続情報を渡さずに開始できます。トークン付きのURLを転用しないでください。
