- [定規](rulers.md)
- [道しるべ](wayfinder.md)
- [Mermaid図の模造](mermaid-imitation.md)
- [ベルを使った操作待ち](bell-conversation.md)

色の候補を返す `colors` は、画面と共通のパレットから生成します。独立した原稿ファイルはありません。
