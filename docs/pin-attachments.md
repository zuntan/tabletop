# ピンをテキスト・図形へ留める

2026-10-19、feat/pin-attachments。線の接合とは別の段階。

## 操作とルール

- ピンをドラッグし、先端（保存座標の下中央）をテキスト・矩形・角丸矩形・楕円のアンカーへ近づけると留まる。
- 新規配置も、アンカーに近ければその場で留まる。
- 対象の移動・リサイズにピン全体が追従する。シリーズの幅・高さが変わっても先端はアンカー位置を保つ。
- ピンだけを動かすと剥がれる。アンカーの近くでは再吸着する。Alt＋ドラッグなら再吸着を抑止できる。
- ピンと対象を一緒に選んだ移動では接着を維持し、一度だけ平行移動する。
- 複数パーツの移動中には、新たな接着先を推測しない。
- ピン同士・線への取り付けはしない。対象がピンに依存しないため、取り付けの連鎖・循環を作らない。
- ピンにつながる線はピンの移動に追従するが、線からピンやその留め先を引っ張らない。
- 対象を削除したらピンはその場に残り、接着だけ外れる。削除のUndoで復元する。
- ピンのマウスロックは直接ドラッグを防ぐが、留め先への追従は妨げない。

## 保存・MCP・コピー

labelのattachmentに{objectId, anchor}を保持する。省略・nullは自由配置。
既存のピンへのupdateで設定・解除する。label_addと同じバッチでupdateしてよい。
MCPは勝手に近くへ吸着させない。UIでの吸着範囲は18画面ピクセル。
接着中の座標は対象から再計算する。MCPでピンだけを座標移動する際はattachment:nullも指定する。

保存・読込・Undo・Redoに対応。旧データは自由配置のまま。
ピンと対象をコピーすれば接着先を新IDへ振り直す。ピンだけなら接着せず通常の追加と同じ採番にする。
シリーズの糸や表示モードは従来通り。

## 確認

単体159件成功。ブラウザでは0.5倍・2倍でのドラッグとAlt取り外し、Undo、既存のピン固定サイズ・糸・線の接合を確認。
吹き出し・図形追加は対象外。
