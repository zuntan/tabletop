# Tabletopの案内

[English](en/README.md)

[変更内容はリリースノートへ](release-notes.md)。

Tabletopは、人間とAIが同じ机に資料を広げ、眺めたり動かしたりしながら考えるための道具です。

このフォルダーには、使い始めるための説明と、必要なときに見返す案内をまとめています。すべてを順番に読む必要はありません。

## まず、机を触ってみる

[チュートリアル机を開く](https://zuntan.github.io/tabletop/?desk=desks/tabletop-guide.tabletop)

インストールやAIへの接続なしで、ブラウザから試せます。中央の案内を読み、緑の道しるべを選んで ▶ を押してみてください。道具の説明とサンプルを行き来できます。

巡り方やPDF版については、[チュートリアル机の案内](./tabletop/README.md)にまとめています。

  置く・選ぶ・動かす・文字を書く・まとめる・保存する。操作を始めるときや、忘れたときの入口です。

## 通常版と静的ページ版

**AIと一緒に作業したいとき**は、通常版を対応するAI環境へMCPで接続します。人間はブラウザで操作し、会話はAIのチャットで続けます。

**作った机を見てもらう・AIなしで試すとき**は、静的ページ版を使えます。人間による基本の編集もでき、変更した机はダウンロードして持ち帰れます。

どちらも .tabletop の机ファイルを使います。静的ページで編集しても、公開元の机は変更されません。

## 続きを残しておく

**机には自動保存がありません。閉じる・再読込する前に保存してください。**

静的ページ版では「ファイル → ダウンロード」で机ファイルを残します。PDFやPNGだけでなく、あとから編集を続けたい場合は .tabletop も保存しておきます。

## 困ったとき

画面のどこにいるか分からなくなったら、選択を外して右下の「全体」を押します。読みたいものを選び、「選択範囲」で寄ることもできます。

操作や保存は[基本操作の説明](./authoring.md)、線のつながりは[図示の説明](./diagram.md)、AI接続は[AIとの利用の説明](./ai-interface.md)へ進んでください。

チュートリアルは使い方の一例です。自分の机では、好きな道具を組み合わせ、使いやすい置き方を見つけてください。
